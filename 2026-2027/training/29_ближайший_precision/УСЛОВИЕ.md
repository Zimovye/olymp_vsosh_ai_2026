# Учебная задача № 5: ближайшее достижимое значение Precision

## Условие задачи

Это **полностью придуманная учебная задача**, основанная на реальной задаче № 5 III группы школьного этапа ВсОШ по искусственному интеллекту 2025/26 для 9–11 классов: `Разбор_школьного_этапа_ВсОШ_по_ИИ_13.pdf`, страницы 5–6. В официальной задаче требовалось найти границы `Precision` при заданном `Accuracy`; здесь изменены данные и вместо границ нужно найти значение, ближайшее к заданной цели.

Классификатор проверил `N = 180` объектов:

- `70` объектов на самом деле относятся к положительному классу;
- `110` объектов относятся к отрицательному классу.

Известно:

```text
Accuracy = (TP + TN) / N = 0,8
```

Требуемое целевое значение точности положительных предсказаний:

```text
target = 18/25
Precision = TP / (TP + FP)
```

Для каждой допустимой матрицы ошибок определим отклонение:

```text
D = |Precision − target|
```

Все четыре количества `TP`, `FP`, `FN`, `TN` должны быть неотрицательными целыми числами. `Precision` должна быть определена, то есть `TP + FP > 0`.

Найдите допустимую матрицу ошибок с наименьшим значением `D`. Для этих данных лучший вариант единственный.

Значения `Precision` и `D` запишите в виде несократимых дробей.

**Что сдаётся:** шесть значений в порядке `TP`, `FP`, `FN`, `TN`, `Precision`, `D`.

## Простое объяснение

По `Accuracy` можно определить общее количество правильных ответов и ошибок. Затем для каждого допустимого целого `TP` восстановите остальные три клетки матрицы.

У каждого варианта вычислите `Precision` и расстояние от него до `18/25`. Выигрывает вариант с наименьшим расстоянием. Сравнивайте точные дроби, чтобы округление не изменило выбор.

Создайте собственный `answer.py` в этой папке. Готового решения и ответа здесь нет.
