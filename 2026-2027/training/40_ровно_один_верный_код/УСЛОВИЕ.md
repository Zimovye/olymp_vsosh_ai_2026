# Учебная задача № 1: ровно один верный код

## Условие задачи

Это **учебная модификация**, а не дополнительная официальная задача и не прогноз комплекта 2026/27.

Источник исходного типа: школьный этап ВсОШ по искусственному интеллекту 2025/26, I группа регионов, 9–11 классы, задание 1 — `Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страница 1.

В Небезопасном Хранилище есть четыре сейфа с номерами 1, 2, 3, 4. Для каждого сейфа существует свой код. Сервер случайно распределяет четыре разных кода по четырём сейфам так, что все `4! = 24` перестановки равновероятны.

Найдите вероятность того, что **ровно один** сейф получит свой верный код.

Перестановки, в которых верный код получили ноль, два, три или четыре сейфа, не подходят.

**Что сдаётся:** одна сокращённая дробь — найденная вероятность.

## Простое объяснение

Представь четыре подписанные коробки и четыре карточки с такими же номерами. Карточки случайно разложили по коробкам. Теперь подходит только такой результат, где номер совпал ровно у одной карточки.

Например, если совпали две карточки, этот вариант уже не подходит: слова «ровно один» означают одновременно «не меньше одного» и «не больше одного».

## Как это будет на платформе

Это учебное условие, поэтому на официальной платформе именно такой задачи может не быть. Если задача с вводом ответа будет сформулирована так же, участник отправит только сокращённую дробь; домашний файл `answer.py` используется для вычисления и не загружается.
