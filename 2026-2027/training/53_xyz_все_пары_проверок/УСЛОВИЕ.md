# Учебная задача № 4: все различающие пары проверок

## Условие задачи

Это **учебный структурно изменённый вариант**, а не официальная задача и не прогноз комплекта 2026/27.

Источник исходного типа: школьный этап ВсОШ по искусственному интеллекту 2025/26, IV группа регионов, 9–11 классы, задача № 4 — `Разбор_школьного_этапа_ВсОШ_по_ИИ_14.pdf`, страницы 2–3.

Система использует одно из четырёх правил для тройки целых чисел `(x, y, z)`:

1. `x < y < z`;
2. `x + y + z > 0`;
3. `x * z == y ** 2`;
4. хотя бы два из чисел `x`, `y`, `z` равны.

Для проверки системы предложены шесть троек:

- `A = (-3, -2, -1)`;
- `B = (-2, 1, 2)`;
- `C = (-2, -2, 1)`;
- `D = (-2, -2, -2)`;
- `E = (-1, 2, 0)`;
- `F = (-1, 1, 1)`.

Выберите две разные проверки. Система ответит «да» или «нет» для каждой из них в соответствии со своим скрытым правилом.

Найдите **все пары проверок**, для которых по двум полученным ответам можно однозначно определить, какое из четырёх правил использует система.

**Что сдаётся:**

1. количество подходящих пар;
2. все подходящие пары букв в алфавитном порядке. Каждую пару записывайте через дефис, например `A-C`.

## Простое объяснение

Для каждой выбранной пары проверок четыре правила дадут четыре пары ответов. Проверки подходят только тогда, когда все четыре пары ответов различны. В этой задаче нужно проверить не одну заранее выбранную пару, а все пары среди `A`–`F` и перечислить все подходящие.

Решение напишите самостоятельно в `answer.py`.

## Как это будет на платформе

Это учебная задача с вводом ответа. На платформе потребовалось бы перенести количество и обозначения найденных пар в поля ответа; вычисляющий файл `.py` не загружается.

В реальной задаче необходимо соблюдать указанный именно в ней формат. Наличие такого варианта на школьном этапе 2026/27 не гарантируется.
