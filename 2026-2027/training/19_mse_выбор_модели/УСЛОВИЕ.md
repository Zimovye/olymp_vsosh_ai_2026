# Выбор модели по средней квадратичной ошибке

## Условие задачи

Источник: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, II группа регионов, 9–11 классы, задание 3: `Разбор_школьного_этапа_ВсОШ_по_ИИ_15.pdf`, страницы 2–3.

Даны два набора точек. Первый называется обучающим, второй — проверочным.

Обучающий набор:

```text
(-0.5, -0.75), (0, -0.5), (0.5, 1.25), (1, 1.5)
```

Проверочный набор:

```text
(2, 5.0), (3, 11.5), (4, 14.0)
```

Рассматриваются четыре модели, задающие зависимость `y` от `x`:

1. `y = 2x`;
2. `y = x + 0.5`;
3. `y = (x + 2)² / 2 − 2`;
4. `y = (x + 1)² − 1`.

Качество модели оценивается по средней квадратичной ошибке:

```text
MSE = ((y₁ − ŷ₁)² + (y₂ − ŷ₂)² + ... + (yₙ − ŷₙ)²) / n
```

Здесь `y` — фактическое значение из точки, а `ŷ` — предсказание модели для того же `x`. Чем меньше MSE, тем лучше модель описывает набор данных.

Нужно:

1. выбрать модель с наименьшей MSE на четырёх точках обучающего набора;
2. выбрать модель с наименьшей MSE на объединённом наборе из всех семи точек.

**Что сдаётся:** выбор двух моделей. В разборе 2025/26 каждый верный выбор оценивался в 6 баллов, всего можно было получить 12 баллов.

## Простое объяснение

Представь, что каждая модель пытается угадать высоту растения по его возрасту. Для каждой точки сравниваем настоящий результат `y` с предсказанием `ŷ`, возводим разницу в квадрат и затем находим среднее.

Квадрат нужен, чтобы ошибки со знаками `+` и `−` не уничтожали друг друга. Лучшая модель — та, у которой среднее квадратов ошибок меньше.

## Маленький готовый пример

Это **учебный изменённый вариант**, а не дополнительное официальное задание.

В `example.py` используются три маленькие точки и две модели: `y = 2x` и `y = x + 1`. Программа для каждой точки печатает настоящее значение, оба предсказания и квадраты ошибок, а затем сравнивает две MSE.

Сначала запусти готовый файл и проследи, как из ошибок отдельных точек получается итоговая MSE. Смотреть в код и менять данные разрешено.

Необязательный видеоразбор исходной задачи: `группа 1, 9–11 классы.mp4`, фрагмент **00:12:29–00:17:19**.

## Как это будет на платформе

В задаче такого формата участник получает координаты точек и формулы моделей прямо в условии. Вычисления можно выполнить своей программой, но для задания с вводом ответа загружать код не нужно: в систему передаются выбранные модели.

Учебный `example.py` печатает пояснения и промежуточные значения. Если похожая задача встретится на школьном этапе 2026/27, нужно внимательно посмотреть точный формат полей ответа; содержание нового комплекта заранее неизвестно.
