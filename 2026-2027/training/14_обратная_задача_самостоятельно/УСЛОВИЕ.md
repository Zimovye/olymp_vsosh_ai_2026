# Самостоятельная задача: фильтр фотографий

## Условие задачи

Это **учебная изменённая задача**, составленная по мотивам реального школьного этапа ВсОШ по искусственному интеллекту 2025/26: I группа регионов, 9–11 классы, задание 5 (`Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страница 5).

Автоматический фильтр проверил `N = 500` фотографий. Положительный класс — фотографии, которые действительно подходят для публикации. Обозначим через `P` общее количество таких фотографий.

- `TP` — подходящие фотографии, которые фильтр верно принял;
- `FP` — неподходящие фотографии, которые фильтр ошибочно принял;
- `FN` — подходящие фотографии, которые фильтр ошибочно отклонил;
- `TN` — неподходящие фотографии, которые фильтр верно отклонил.

Метрики:

```text
Precision = TP / (TP + FP)
Accuracy = (TP + TN) / N
```

Известно, что `Accuracy = 0,4` и `Precision = 0,5`.

Найдите:

1. значение `P`;
2. минимальное возможное значение `TP`;
3. максимальное возможное значение `TP`.

Все количества фотографий должны быть неотрицательными целыми числами. Значение `Precision` должно быть определено, то есть `TP + FP > 0`.

**Что сдаётся:** три целых числа — `P`, нижняя и верхняя границы `TP`.

## Простое объяснение

Сначала по `Accuracy` определите общее количество верных ответов и ошибок. Затем используйте связь между `TP` и `FP`, которая следует из `Precision = 0,5`.

При поиске границ `TP` проверьте сразу два условия: `FN` и `TN` не могут быть отрицательными. В этой задаче более строгим окажется не то ограничение, которое было в предыдущем примере.

Создайте собственный `answer.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В задании такого формата участник вводит три числа в указанные поля. Программу можно использовать для вычислений и проверки, но вместо числового ответа файл `.py` не загружается.
