# Учебная задача № 5: минимальное число принятых снимков

## Условие задачи

Это **полностью придуманная учебная задача**, основанная на реальной задаче № 5 II группы школьного этапа ВсОШ по искусственному интеллекту 2025/26 для 9–11 классов: `Разбор_школьного_этапа_ВсОШ_по_ИИ_15.pdf`, страницы 4–5. В официальной задаче требовалось найти диапазон `Recall`; здесь добавлено требование к минимальному `Recall`, изменены данные и поставлена задача минимизации.

Система проверила `N = 200` фотографий. Из них `P = 120` действительно подходят для публикации, а остальные 80 не подходят.

- `TP` — подходящие фотографии, которые система верно приняла;
- `FP` — неподходящие фотографии, которые система ошибочно приняла;
- `FN` — подходящие фотографии, которые система ошибочно отклонила;
- `TN` — неподходящие фотографии, которые система верно отклонила.

Метрики:

```text
Precision = TP / (TP + FP)
Recall = TP / P
```

Известно, что система должна одновременно выполнять два требования:

```text
Precision = 0,75
Recall >= 0,8
```

Найдите минимально возможное количество фотографий, которые система пометит как подходящие, то есть минимальное значение `TP + FP`.

Для найденного минимума также укажите `TP`, `FP`, `FN` и `TN`.

Все четыре количества должны быть неотрицательными целыми числами. Значения метрик должны быть определены.

**Что сдаётся:** пять целых чисел в порядке `TP + FP`, `TP`, `FP`, `FN`, `TN`.

## Простое объяснение

Точное значение `Precision = 0,75` задаёт целочисленное соотношение между `TP` и `FP`. Условие `Recall >= 0,8` устанавливает, сколько из 120 действительно подходящих фотографий нужно найти как минимум.

Нужно перебрать допустимые целые пары `TP`, `FP`, проверить оба требования и выбрать вариант с наименьшей суммой `TP + FP`. После этого восстановите `FN` и `TN` из размеров двух настоящих классов.

Создайте собственный `answer.py` в этой папке. Готового решения и ответа здесь нет.
