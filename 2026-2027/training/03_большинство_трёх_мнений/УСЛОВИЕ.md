# Самостоятельная задача: большинство трёх мнений

## Условие задачи

Это **учебная задача** с маленькими данными, составленная по мотивам реального школьного этапа ВсОШ по искусственному интеллекту 2025/26: II группа регионов, 9–11 классы, задание 6 (`Разбор_школьного_этапа_ВсОШ_по_ИИ_15.pdf`, страницы 5–6).

Перед подачей каждого блюда три человека высказывают мнение, понравится ли оно наследнику Тутти:

- `1` — блюдо понравится;
- `0` — блюдо не понравится.

В каждой строке файла `data.csv` записаны четыре целых числа:

- `n1`, `n2`, `n3` — мнения трёх человек;
- `y` — фактическое решение Тутти.

Повар делает предсказание по правилу большинства:

- если `n1 + n2 + n3 >= 2`, предсказание равно `1`;
- иначе предсказание равно `0`.

Найдите количество строк, в которых предсказание повара совпало с фактическим решением `y`.

**Что сдаётся:** одно целое число.

Оригинального файла с данными в нашем архиве нет. Файл `data.csv` в этой папке — проверенный учебный набор, а не восстановленные официальные данные.

## Простое объяснение

В каждой строке нужно посмотреть на три мнения. Если хотя бы два человека выбрали `1`, большинство предсказывает `1`. В остальных случаях большинство предсказывает `0`.

Полученное предсказание сравнивается с `y`. В ответе требуется количество совпадений во всей таблице.

Создайте собственный файл `.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В официальной задаче участник скачивал таблицу в формате XLSX, ODS или CSV, вычислял количество совпадений и вводил в поле ответа одно число. Код и таблицу вместо ответа загружать не требовалось.
