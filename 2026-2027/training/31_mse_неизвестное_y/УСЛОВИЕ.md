# Учебная задача № 3: MSE при неизвестном значении `y`

## Условие задачи

Это **учебная модификация**, а не официальное задание и не прогноз комплекта 2026/27.

Источник исходного типа задачи: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, II группа регионов, 9–11 классы, задание 3 — `Разбор_школьного_этапа_ВсОШ_по_ИИ_15.pdf`, страницы 2–3.

Даны две точки:

```text
(1, 2)
(3, y)
```

Значение `y` во второй точке неизвестно. Известно, что это целое число от 0 до 10 включительно.

Рассматриваются две модели:

```text
Модель 1: ŷ = x + 1
Модель 2: ŷ = 2x
```

Качество модели оценивается по средней квадратичной ошибке:

```text
MSE = ((y₁ − ŷ₁)² + (y₂ − ŷ₂)²) / 2
```

Чем меньше MSE, тем лучше модель описывает две точки.

Переберите все допустимые целые значения неизвестного `y` и найдите:

1. значения `y`, при которых MSE модели 1 строго меньше MSE модели 2;
2. значения `y`, при которых MSE обеих моделей равны;
3. значения `y`, при которых MSE модели 2 строго меньше MSE модели 1.

**Что сдаётся:** три строки. В первой — значения для модели 1, во второй — значения ничьей, в третьей — значения для модели 2. Внутри каждой строки числа записываются по возрастанию через пробел.

## Простое объяснение

В предыдущей задаче MSE все точки уже были известны, и требовалось выбрать лучшую модель. Здесь одна координата `y` меняется, поэтому победитель тоже может измениться.

Для каждого целого `y` от 0 до 10 нужно отдельно вычислить две MSE и добавить `y` в один из трёх списков: победа первой модели, ничья или победа второй модели.

Создай `answer.py` в этой папке. Готового решения здесь нет. Сравнивай вычисленные MSE до округления.

## Как это будет на платформе

В реальной задаче формат ответа задаёт платформа. Неизвестное значение `y` и требование разделить значения на три группы придуманы для тренировки и не взяты из официального комплекта.
