# Учебная задача № 4: определить правило по двум ответам

## Условие задачи

Это **учебный структурно изменённый вариант**, а не официальная задача и не прогноз комплекта 2026/27.

Источник исходного типа: школьный этап ВсОШ по искусственному интеллекту 2025/26, IV группа регионов, 9–11 классы, задача № 4 — `Разбор_школьного_этапа_ВсОШ_по_ИИ_14.pdf`, страницы 2–3.

Программа использует одно из четырёх правил для пары целых чисел `(x, y)`:

1. `x > 0`;
2. `y > 0`;
3. `x + y > 0`;
4. `x * y > 0`.

Были проведены две проверки:

- первая пара: `(-1, 2)`;
- вторая пара: `(1, 0)`.

На первую проверку программа ответила **«нет»**, на вторую — тоже **«нет»**.

Определите номер правила, которое использует программа.

**Что сдаётся:** одно целое число — номер правила.

## Простое объяснение

Для каждого из четырёх правил нужно определить два ответа: сначала для пары `(-1, 2)`, затем для пары `(1, 0)`. Подходит то правило, у которого получится пара ответов `(нет, нет)`.

Это обратный вариант предыдущей задачи: теперь проверки уже выбраны и известны их результаты, а найти нужно скрытое правило.

Решение запишите самостоятельно в `answer.py`.

## Как это будет на платформе

Это учебная задача с вводом ответа. На платформе в поле ответа вводилось бы одно целое число; вычисляющий файл `.py` загружать не нужно.

В реальном условии нужно заново проверить, что именно требуется отправить. Наличие такого варианта на школьном этапе 2026/27 не гарантируется.
