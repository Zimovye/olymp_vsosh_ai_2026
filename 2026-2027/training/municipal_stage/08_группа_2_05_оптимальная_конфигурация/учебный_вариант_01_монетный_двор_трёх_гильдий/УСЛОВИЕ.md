# Учебная модификация № 1. Монетный двор трёх гильдий

## Условие задачи

Это придуманная учебная модификация, не официальная задача олимпиады.

Основа: группа II, № 5 «Оптимальная конфигурация», муниципальный этап ВсОШ по ИИ 2025/26, 9–11 классы; [исходный PDF](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа2_Текстовый_разбор.pdf>), с. 4–5. Сохранены залы по 8 мест, точное соотношение двух групп и поиск минимального числа залов. Изменение — добавлена третья группа фиксированного размера: теперь подходящего распределения может не существовать. При успехе требуется также вывести распределение первых двух групп. Это упражнение на изменение условия знакомой задачи, не прогноз варианта 2026/27.

В королевстве открывают монетный двор. Для мастеров можно арендовать любое положительное целое число залов. В каждом зале ровно 8 рабочих мест, и все места в арендованных залах должны быть заняты.

На монетном дворе работают три гильдии:

- **Рисовальщики** создают рисунки будущих монет. Нужен хотя бы один рисовальщик.
- **Чеканщики** изготовляют монеты. По всему монетному двору их должно быть ровно в $k$ раз больше, чем рисовальщиков.
- **Пробирщики** проверяют качество металла. Их должно быть ровно $r$ на весь монетный двор; это число менять нельзя.

Каждый мастер относится ровно к одной гильдии и занимает одно рабочее место. Мастера разных гильдий могут находиться в одном зале. Рисовальщиков и чеканщиков можно нанимать в любом количестве с соблюдением указанного соотношения.

Найдите минимальное число залов, при котором все требования выполняются. Для этого числа залов определите количество рисовальщиков и чеканщиков. Если выполнить требования невозможно, сообщите об этом.

**Формат входных данных**

Одна строка содержит два целых числа $k$ и $r$ через пробел:

$$
1 \leq k \leq 1\,000\,000, \qquad 0 \leq r \leq 1\,000\,000.
$$

**Формат выходных данных**

Если распределение существует, выведите в одной строке три целых числа через пробел:

1. Минимальное число залов.
2. Число рисовальщиков.
3. Число чеканщиков.

Если распределения не существует, выведите одно число $-1$.

**Пример 1**

Ввод:

```text
5 4
```

Вывод:

```text
2 2 10
```

**Пример 2**

Ввод:

```text
7 1
```

Вывод:

```text
-1
```

## Простое объяснение

Представь комнаты с восемью стульями. Нужно посадить всех работников так, чтобы пустых стульев не осталось. Чеканщиков нанимаем в нужном соотношении с рисовальщиками, а число проверяющих металл уже задано королевским указом.

Ищем самый маленький подходящий монетный двор и сообщаем, сколько в нём залов и работников двух первых гильдий. Иногда приказ о числе пробирщиков несовместим с остальными требованиями — для этого предусмотрен ответ $-1$.

**Как это будет на платформе**

Это домашнее упражнение без страницы в официальном туре. Для учебной проверки сохраняй программу в обычном `answer.py`: вход — одна строка с $k$ и $r$, выход — три целых числа либо $-1$. Во время решения можно оставлять промежуточные `print()`; при подготовке к проверке оставить только требуемый результат.

В исходной официальной задаче 2025/26 программа получает только $k$ и выводит только минимальное число нод. Точный регламент муниципального этапа 2026/27 ещё не подтверждён.
