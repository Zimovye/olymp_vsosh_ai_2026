# Группа II, № 5. Оптимальная конфигурация

## Условие задачи

Оригинальная задача муниципального этапа ВсОШ по ИИ 2025/26 для 9–11 классов, вариант II. Восьмая задача в согласованном порядке подготовки.

Источник: [МЭ25_ИИ_9-11_Группа2_Текстовый_разбор.pdf](<../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа2_Текстовый_разбор.pdf>), с. 4 — условие и начало разбора, с. 5 — код разбора. [Официальная страница архива](https://siriusolymp.ru/2025/municipal/ai).

Ограничение по времени: 1 секунда.

Ограничение по памяти: 256 мегабайт.

Обучение больших нейронных сетей происходит на кластере — вычислительной инфраструктуре, которая позволяет использовать одновременно большое количество видеокарт. Видеокарты на кластере объединяются в ноды (блоки по 8 карт).

Для обучения больших языковых моделей методом обучения с подкреплением видеокарты делятся на два типа: одни генерируют данные, другие обновляют веса модели на основе генерированных данных. Вторая задача гораздо сложнее, поэтому при наилучшем распределении ресурсов на неё должно выделяться в $k$ раз больше видеокарт. Обучение с оптимальным распределением ресурсов мы будем называть оптимальным.

Вы работаете в очень большой компании, поэтому ваши ресурсы не ограничены. Вы хотите выделить минимальное количество нод так, чтобы их видеокарты можно было разбить на два вышеописанных типа так, чтобы обучение при этом было оптимальным.

**Формат входных данных**

В первой и единственной строке входных данных вводится одно целое число $k$ ($1 \leq k \leq 1\,000\,000$).

**Формат выходных данных**

Выведите одно число: минимальное число нод, которые нужно выделить так, чтобы обучение было оптимальным.

**Пример**

Стандартный ввод:

```text
5
```

Стандартный вывод:

```text
3
```

Максимальный балл за задание в исходном комплекте 2025/26 — 100. Это исторические сведения об этой задаче, а не подтверждённая шкала муниципального этапа 2026/27.

## Простое объяснение

Представь, что компьютеры выдают только целыми коробками по 8 штук. Нужно занять все компьютеры из выбранных коробок: одни готовят данные, остальные обновляют модель. Нода — это такая «коробка» из 8 видеокарт. Устройство нейросети для решения знать не нужно.

Если данные готовят $x$ карт, то обновлением занимаются $kx$ карт. Всего нужно

$$
x+kx=(k+1)x
$$

карт. Это количество должно делиться на 8 без остатка. Требуется найти наименьшее число нод, а не число карт и не число групп.

Для $k=5$ одна карта готовит данные, пять обновляют модель: вместе 6 карт. При увеличении числа карт для генерации получаем:

| Карты для генерации | Карты для обновления | Всего карт | Делится на 8? |
|---:|---:|---:|:---|
| 1 | 5 | 6 | Нет |
| 2 | 10 | 12 | Нет |
| 3 | 15 | 18 | Нет |
| 4 | 20 | 24 | Да: $\frac{24}{8}=3$ ноды |

Перебираем $x$ по возрастанию и останавливаемся на первом подходящем варианте: при увеличении $x$ общее число карт тоже растёт. Достаточно проверить $x$ от 1 до 8. При $x=8$ всего будет $8(k+1)$ карт, а это всегда делится на 8. Таким образом, даже при максимальном $k$ нужно не больше восьми проверок.

`example.py` — готовый учебный пример с поясняющим выводом. Он читает число с клавиатуры и решает исходную задачу для любого допустимого значения. Начни с ввода 5.

**Ошибка архивного разбора.** На с. 4 написано, что общее число карт должно делиться на 8 и на $k$, а на с. 5 приведён код `lcm(k, 8) // 8`. Из условия следует делимость на $k+1$. При $k=5$ напечатанный код выдаёт 5, хотя в примере правильный ответ — 3. Исходный PDF не изменён; готовый учебный пример следует условию.

**Как это будет на платформе**

В исходной задаче 2025/26 это программное задание. Программа получает одно целое число $k$ через стандартный ввод; скачиваемой таблицы нет. Отправляется программа, которая для входного числа печатает одно целое число — минимальное число нод. Значение 5 в примере не является постоянным входом.

Для нашей практики используется Python 3 и обычный файл `.py`. Перед сдачей нужно убрать промежуточный вывод и подписи: в `example.py` оставить только `print(nodes)` в подходящей ветке. Чтение через `input()` и вычисления сохранить. Точные условия площадки муниципального этапа 2026/27 ещё не подтверждены; школьные правила отправок автоматически сюда не переносим.
