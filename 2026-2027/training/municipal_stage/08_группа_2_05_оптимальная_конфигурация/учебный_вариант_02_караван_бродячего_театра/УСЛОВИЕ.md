# Учебная модификация № 2. Караван бродячего театра

## Условие задачи

Это придуманная учебная модификация, не официальная задача олимпиады.

Основа: группа II, № 5 «Оптимальная конфигурация», муниципальный этап ВсОШ по ИИ 2025/26, 9–11 классы; [исходный PDF](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа2_Текстовый_разбор.pdf>), с. 4–5. Сохраняются блоки по 8 мест и точное соотношение двух групп; фиксированная третья группа знакома по модификации № 1. Новое изменение цели: при заданном запасе повозок нужно посчитать все допустимые размеры каравана и найти их границы. Это упражнение на перебор и обработку всех подходящих вариантов в рамках знакомой темы, не прогноз заданий 2026/27.

Бродячий театр отправляется выступать в замках королевства. У него есть $B$ повозок, в каждой ровно 8 мест. Театр может взять любое целое число повозок от 1 до $B$ включительно. Все места в выбранных повозках должны быть заняты участниками труппы.

В труппе три группы:

- **Сказители** рассказывают истории. Нужен хотя бы один сказитель.
- **Кукловоды** показывают события этих историй. Их должно быть ровно в $k$ раз больше, чем сказителей.
- **Музыканты** сопровождают выступление. Их должно быть ровно $r$ во всей труппе; это число менять нельзя.

Каждый участник относится ровно к одной группе и занимает одно место. Участники разных групп могут ехать в одной повозке. Сказителей и кукловодов можно приглашать в любом количестве с соблюдением указанного соотношения.

Посчитайте, сколько различных чисел повозок позволяют выполнить все требования. Также найдите наименьшее и наибольшее подходящие числа повозок.

Рассадки участников внутри повозок отдельно не считаются: для каждого числа повозок учитывается только возможность набрать подходящую труппу.

**Формат входных данных**

Одна строка содержит три целых числа $k$, $r$ и $B$ через пробел:

$$
1 \leq k \leq 1\,000\,000, \qquad
0 \leq r \leq 1\,000\,000, \qquad
1 \leq B \leq 100\,000.
$$

**Формат выходных данных**

Выведите в одной строке три целых числа через пробел:

1. Количество подходящих чисел повозок.
2. Наименьшее подходящее число повозок.
3. Наибольшее подходящее число повозок.

Если подходящих вариантов нет, выведите `0 0 0`.

**Пример 1**

Ввод:

```text
5 4 10
```

Вывод:

```text
3 2 8
```

**Пример 2**

Ввод:

```text
8 0 8
```

Вывод:

```text
0 0 0
```

## Простое объяснение

Представь театральную поездку: руководитель выбирает, сколько повозок взять и сколько исполнителей пригласить. Число музыкантов уже известно, а сказителей и кукловодов нужно набрать в нужном соотношении. Пустых мест в выбранных повозках быть не должно.

Теперь требуется узнать, сколько размеров каравана допустимо при имеющемся запасе повозок, и указать самый маленький и самый большой. $B$ — это верхний предел: брать все имеющиеся повозки необязательно.

**Как это будет на платформе**

Это домашнее упражнение без страницы в официальном туре. Для учебной проверки сохраняй программу в обычном `answer.py`: вход — одна строка с $k$, $r$ и $B$, выход — одна строка с тремя целыми числами. Во время решения можно оставлять промежуточные `print()`; при подготовке к проверке оставить только требуемый результат.

В исходной официальной задаче 2025/26 программа получает только $k$ и выводит только минимальное число нод. Точный регламент муниципального этапа 2026/27 ещё не подтверждён.
