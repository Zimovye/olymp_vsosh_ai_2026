# Группа III, № 3. Минимизация L1 и L2

## Условие задачи

Официальная задача муниципального этапа ВсОШ по искусственному интеллекту 2025/26, группа III, 9–11 классы, № 3.

Источник: [МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf, страница 2](<../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf>). На этой странице находятся исходное условие и авторское решение.

Вы настраиваете простейшую регрессионную модель, которая всегда предсказывает одно и то же число $c$ (константная модель). Дан набор истинных значений:

$$
y = \{1, 2, 3, 9, 10, 10\}.
$$

Рассмотрим две функции качества:

$$
L_1(c) = \sum_i |y_i - c|
\qquad\text{и}\qquad
L_2(c) = \sum_i (y_i - c)^2.
$$

**а)** Найдите значение $c_1$, минимизирующее $L_1(c)$. Если оптимальных значений несколько, в ответ запишите наименьшее.

**б)** Найдите значение $c_2$, минимизирующее $L_2(c)$. Если оптимальных значений несколько, в ответ запишите наименьшее.

**Что сдаётся:** значения $c_1$ и $c_2$ для подпунктов а) и б). Сами суммы ошибок в ответе не требуются.

## Простое объяснение

Представь, что известна длительность нескольких поездок, а приложение всем показывает одно и то же ожидаемое время $c$. Настоящая длительность одной поездки — это $y_i$. Нужно подобрать общее предсказание так, чтобы суммарная ошибка была как можно меньше.

- $L_1$: для каждой поездки берём расстояние между настоящим временем и предсказанием, затем складываем. Ошибка на 3 минуты даёт вклад 3 независимо от того, в какую сторону ошиблись.
- $L_2$: каждую разность сначала возводим в квадрат, затем складываем. Ошибка на 3 минуты даёт вклад 9, поэтому большие промахи сильнее влияют на результат.

Для двух способов подсчёта выбираем $c$ отдельно. «Минимизировать» означает найти такое $c$, при котором сумма меньше всего. Требуются сами предсказания, а не величины ошибок.

### Маленький готовый пример

**Учебный пример с изменёнными данными, не отдельная официальная задача:** те же два подпункта для набора

$$
y = \{7, 1, 6, 2\}.
$$

Рабочий код — [example.py](example.py). Сначала он показывает обе суммы ошибок при нескольких целых значениях $c$, затем вычисляет ответы по правилу из авторского разбора:

- для $L_1$ при чётном количестве значений подходят все числа между двумя средними элементами отсортированного набора; выбираем левый край, поскольку нужен наименьший ответ;
- для $L_2$ подходит среднее арифметическое.

Перебор целых значений в примере нужен, чтобы увидеть вычисления. В самой задаче $c$ может быть и дробным; правило для среднего это учитывает.

### Как это будет на платформе

В этой архивной задаче участник получает набор чисел прямо в условии; скачивать таблицу не требуется. Для подпунктов а) и б) вводятся найденные $c_1$ и $c_2$, а не программа и не значения $L_1$ и $L_2$.

Чтобы перейти от учебного кода к исходной задаче, нужно заменить только набор `y`. `Fraction` сохраняет среднее точной дробью. Промежуточные сообщения можно оставить при локальном расчёте: в поля ответа переносим только два результата, каждый в свой подпункт. Точный вид полей и допустимую запись дроби нужно сверять с инструкцией площадки; правила муниципального этапа 2026/27 этим архивным разбором не подтверждаются.
