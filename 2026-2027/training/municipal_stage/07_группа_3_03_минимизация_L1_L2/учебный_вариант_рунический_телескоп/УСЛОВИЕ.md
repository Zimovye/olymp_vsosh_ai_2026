# Рунический телескоп

## Условие задачи

**Учебная модификация, не официальная задача ВсОШ.** Основа: муниципальный этап 2025/26, группа III, № 3 «Минимизация L1 и L2», [МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf, с. 2](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf>).

В башне звёздочётов установлен рунический телескоп. Для каждой наблюдаемой звезды известно идеальное положение линзы. Но во время общего сеанса линзу нужно оставить в одном положении $c$ для всех звёзд.

Звёзды с одинаковым идеальным положением объединены в строки. Число $x_i$ — идеальное положение линзы, $k_i$ — количество звёзд, которым оно подходит.

| Идеальное положение $x_i$ | Количество звёзд $k_i$ |
|---:|---:|
| 2 | 3 |
| 5 | 7 |
| 8 | 2 |
| 11 | 4 |
| 14 | 3 |
| 20 | 1 |

У телескопа шесть фиксированных положений переключателя. Можно выбрать только

$$
c \in \{12,\ 7,\ 3,\ 9,\ 6,\ 18\}.
$$

Другие положения, в том числе промежуточные между разрешёнными, использовать нельзя.

Каждая звезда учитывается отдельно. Ошибки настройки определяются так:

$$
L_1(c)=\sum_{i=1}^{6} k_i|x_i-c|,
\qquad
L_2(c)=\sum_{i=1}^{6} k_i(x_i-c)^2.
$$

**а)** Найдите разрешённое положение $c_1$, при котором $L_1(c)$ минимальна.

**б)** Независимо от пункта а) найдите разрешённое положение $c_2$, при котором $L_2(c)$ минимальна.

Если в каком-либо пункте оптимальных положений несколько, выберите наименьшее числовое значение положения.

**Формат учебного ответа:** две строки. В первой — целое число $c_1$, во второй — целое число $c_2$. Требуются положения переключателя; сами значения функций ошибки выводить не нужно.

Данные записаны в соседнем [answer.py](answer.py): `values` — идеальные положения, `counts` — соответствующие количества звёзд, `settings` — разрешённые положения переключателя. Решения в файле нет.

## Простое объяснение

Это похоже на лампу с несколькими готовыми режимами яркости: выбрать можно только существующий режим. У телескопа такими режимами служат числа из списка `settings`.

Строка «5, 7» означает семь звёзд с идеальным положением 5. Для всех звёзд выбираем одну общую настройку, отдельно для каждого способа подсчёта ошибки.

**Что изменено:** относительно «Грифоньей почты» сохранены данные с повторениями и обе функции ошибки. Меняется одно существенное условие — теперь $c$ выбирается из конечного списка разрешённых настроек. Ограничение на настройки является учебным изменением; оно не подтверждает содержание заданий сезона 2026/27.

### Как это будет на платформе

У этой учебной модификации нет официальной страницы сдачи. Все данные находятся в условии и `answer.py`; скачивать таблицу не требуется. Итог самостоятельной попытки — два целых положения в указанном формате. Во время разбора можно печатать таблицу ошибок для наблюдения.

В исходной архивной задаче группы III, № 3 участник получает числа прямо в условии и вводит найденные значения по двум подпунктам. Программа служит для локального расчёта; в поля ответа переносятся только результаты. Точные поля и правила муниципального этапа 2026/27 проверяются по инструкции его площадки.
