# Драконий инкубатор

## Условие задачи

**Учебная модификация, не официальная задача ВсОШ.** Основа: муниципальный этап 2025/26, группа III, № 3 «Минимизация L1 и L2», [МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf, с. 2](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf>).

В драконьем питомнике шесть кладок яиц обогреваются одним магическим кристаллом. Для каждой кладки известно идеальное значение тепла в условных единицах:

$$
y = (3,\ 20,\ 5,\ 16,\ 7,\ 9).
$$

Кристалл поддерживает одно общее значение $c$ для всех кладок. Оно может быть **любым действительным числом**, в том числе дробным. Фиксированного списка разрешённых настроек нет.

Хранитель питомника рассматривает два способа оценить настройку.

Первый — наибольшее абсолютное отклонение среди всех кладок:

$$
F(c)=\max_{1\leq i\leq 6}|y_i-c|.
$$

Второй — сумма квадратов отклонений:

$$
L_2(c)=\sum_{i=1}^{6}(y_i-c)^2.
$$

**а)** Найдите значение $c_1$, при котором $F(c)$ минимальна.

**б)** Независимо от пункта а) найдите значение $c_2$, при котором $L_2(c)$ минимальна.

Если в каком-либо пункте оптимальных значений несколько, выберите наименьшее.

**Формат учебного ответа:** две строки. В первой — $c_1$, во второй — $c_2$. Дробное число запишите точной сокращённой обыкновенной дробью, целое — целым числом. Требуются сами значения тепла, а не значения функций ошибки.

Все шесть кладок учитываются по одному разу. Данные уже записаны в соседнем [answer.py](answer.py); решения в нём нет.

## Простое объяснение

Представь одну настройку отопления для нескольких комнат, которым подходят разные температуры. Для каждой комнаты можно посчитать расстояние от выбранной температуры до подходящей ей.

Здесь $F(c)$ оценивает самый большой промах. Например, если отклонения равны 2, 3 и 5, эта оценка равна 5. Сумма квадратов для тех же отклонений равна $2^2+3^2+5^2=38$.

Нужно отдельно подобрать лучшее общее значение для каждого способа оценки.

**Что изменено относительно исходной задачи:** в первом пункте сумма абсолютных отклонений заменена их максимумом. Свободный выбор действительного $c$ и второй критерий сохранены. Это упражнение на поиск оптимального постоянного предсказания при изменении самой функции ошибки. Использование максимума — учебное изменение, а не подтверждённая особенность муниципального этапа 2026/27.

### Как это будет на платформе

У этой учебной модификации нет официальной страницы сдачи. Числа даны прямо в условии и `answer.py`, скачивать файл данных не нужно. Результат попытки — два найденных значения в указанном формате; во время обучения можно выводить промежуточные вычисления.

В исходной архивной задаче группы III, № 3 участник также получает числа прямо в условии и вводит ответы по двум подпунктам. Код используется для локального расчёта; в поля ответа переносятся только результаты. Точные поля и правила муниципального этапа 2026/27 проверяются по инструкции его площадки.
