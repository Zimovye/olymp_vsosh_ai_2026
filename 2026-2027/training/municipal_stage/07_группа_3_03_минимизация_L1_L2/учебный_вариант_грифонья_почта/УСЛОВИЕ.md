# Грифонья почта

## Условие задачи

**Учебная модификация, не официальная задача ВсОШ.** Основа: муниципальный этап 2025/26, группа III, № 3 «Минимизация L1 и L2», [МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf, с. 2](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf>).

В горном королевстве письма доставляют на грифонах. Почтмейстер хочет указывать всем заказчикам одно и то же предсказанное время доставки $c$ в днях. Для настройки предсказания он изучает завершённые доставки.

В журнале одинаковые длительности объединены: для каждой длительности $t_i$ записано количество доставок $k_i$, которые заняли ровно столько дней.

| Длительность $t_i$, дней | Количество доставок $k_i$ |
|---:|---:|
| 2 | 3 |
| 5 | 7 |
| 8 | 2 |
| 11 | 4 |
| 14 | 3 |
| 20 | 1 |

Каждая завершённая доставка учитывается отдельно. Поэтому две функции ошибки имеют вид:

$$
L_1(c)=\sum_{i=1}^{6} k_i|t_i-c|,
\qquad
L_2(c)=\sum_{i=1}^{6} k_i(t_i-c)^2.
$$

Число $c$ может быть любым действительным числом, в том числе дробным.

**а)** Найдите предсказание $c_1$, при котором $L_1(c)$ минимальна.

**б)** Независимо от пункта а) найдите предсказание $c_2$, при котором $L_2(c)$ минимальна.

Если для какого-либо пункта оптимальных значений несколько, выберите наименьшее.

**Формат учебного ответа:** две строки. В первой — $c_1$, во второй — $c_2$. Дробный ответ запишите точной сокращённой обыкновенной дробью; целый — целым числом. Сами суммы ошибок выводить не требуется.

Данные для работы уже записаны в соседнем [answer.py](answer.py); решения в нём нет.

## Простое объяснение

Строка «5 дней, 7 доставок» означает семь отдельных доставок длительностью по 5 дней. Например, если предсказывать им 4 дня, каждая даст ошибку в 1 день: суммарный вклад этой строки в $L_1$ равен 7, в $L_2$ — тоже 7.

Нужно выбрать общее предсказание для каждого способа подсчёта ошибки. Учитывай, что строки таблицы представляют разное количество доставок.

**Что изменено относительно исходной задачи:** наблюдения даны с количеством повторений. Это содержательное изменение представления данных; смысл L1 и L2 и оба подпункта сохранены. Такое представление выбрано для закрепления той же задачи, а не как прогноз задания муниципального этапа 2026/27.

### Как это будет на платформе

У этой учебной модификации нет официальной страницы сдачи. Здесь данные находятся в условии и в `answer.py`, скачивать CSV не требуется. Результат самостоятельной попытки — два найденных предсказания в указанном формате.

В исходной архивной задаче группы III, № 3 участник также получает числа прямо в условии и вводит ответы по двум подпунктам. Программа служит для локального расчёта. Перед переносом результата в поля ответа берутся только найденные значения; учебные сообщения в поля не копируются. Точный вид полей муниципального этапа 2026/27 проверяется по инструкции его площадки.
