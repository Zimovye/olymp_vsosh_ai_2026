# Знаменосцы Лунного турнира

## Условие задачи

**Учебная модификация для самостоятельного решения.** Сюжет, данные и выбор представителей по орденам составлены Codex. Это не официальная задача и не прогноз задания будущего тура.

В Лунном королевстве проходят рыцарские испытания. Зачарованная летопись записывает результаты владения копьём, мечом и верховой езды. Каждый орден должен выбрать знаменосца среди своих рыцарей, допущенных в серебряный разряд турнира.

В файле [knights.csv](knights.csv) находятся 32 записи с шестью столбцами:

| Столбец | Значение |
|---|---|
| order_id | Номер рыцарского ордена, положительное целое число. |
| knight_id | Номер рыцаря, положительное целое число. |
| trial | Испытание: «копьё», «меч» или «выездка». |
| score | Полученный балл, вещественное число; иногда отсутствует. |
| cheat_flag | Подозрение на использование запрещённых чар: True или False. |
| attempt_no | Номер попытки, положительное целое число; 1 означает первую попытку. |

Кодировка — UTF-8, разделитель — запятая, десятичный знак — точка. Первая строка содержит названия столбцов. Пропуски встречаются только в *score* и обозначены пустыми полями. Строки перемешаны. Номер рыцаря уникален для королевства: один рыцарь всегда относится к одному ордену, поэтому во всех его строках *order_id* одинаков.

**Подготовьте данные.**

1. В столбце *score* замените пропуски на 0, значения меньше 0 — на 0, а значения больше 100 — на 100.
2. Удалите строки, в которых *cheat_flag* равен True.
3. Оставьте только первые попытки: *attempt_no* = 1.
4. Для каждого рыцаря найдите среднее всех его баллов, оставшихся после этих действий. Если у рыцаря не осталось допустимых записей, он не участвует в дальнейшем отборе.

В серебряный разряд допускается рыцарь, средний балл которого удовлетворяет условию

$$
60 \leqslant \text{avg\_score} < 80.
$$

Средние значения перед сравнением и выбором знаменосцев не округляйте.

**Выберите знаменосцев.**

Для каждого ордена:

- посчитайте число рыцарей, допущенных в серебряный разряд;
- среди этих рыцарей выберите знаменосца с наибольшим средним баллом;
- при равенстве наибольших средних выберите рыцаря с наименьшим *knight_id*;
- если допущенных рыцарей нет, вместо номера знаменосца укажите 0.

Рыцарь со средним баллом 80 или выше не может стать знаменосцем серебряного разряда, даже если его среднее больше всех остальных. Один рыцарь учитывается в количестве один раз, независимо от числа его оставшихся работ.

**Формат результата.**

Для каждого ордена, встречавшегося в исходном CSV, выведите по одной строке в порядке возрастания *order_id*. Строка содержит три целых числа через пробел:

1. номер ордена;
2. количество допущенных рыцарей этого ордена;
3. номер выбранного знаменосца или 0.

Орден, у которого не осталось ни одного подходящего рыцаря или вообще ни одной допустимой записи, тоже выведите: после его номера должны стоять два нуля. Заголовки и номера строк не печатайте.

Последней строкой выведите одно целое число — общее количество рыцарей серебряного разряда по всем орденам. Здесь считается число рыцарей, а не только выбранных знаменосцев.

## Простое объяснение

Сначала выполняется знакомая обработка: исправляем баллы, убираем запрещённые чары и повторные попытки, вычисляем среднее каждого рыцаря. По среднему определяем, кто попал в серебряный разряд.

Новое — отдельный выбор знаменосца внутри каждого ордена. Например, если средние трёх рыцарей одного ордена равны 70, 76 и 90, подходят двое, а знаменосцем становится рыцарь со средним 76. При одинаковых лучших средних решает меньший номер рыцаря. В конце нужен отчёт по всем орденам и общее число допущенных участников.

### Как это будет на платформе

В этой учебной задаче ты получаешь CSV и своей программой формируешь результат: по три целых числа для каждого ордена, затем одно общее количество. При подготовке итогового вывода оставь только эти строки; в процессе разбора промежуточные `print()` разрешены и полезны.

В исходной муниципальной задаче 2025/26 скачивалась таблица и вводилось одно число. Наш подробный отчёт и выбор знаменосцев — домашнее усложнение; формат будущей официальной задачи определяется её собственным условием.
