Система электронного тестирования фиксирует результаты проверочных работ школьников, которые вы можете скачать в форматах XLSX, ODS или CSV. Файл содержит пять столбцов:

- *student_id* — идентификатор ученика (целое число);
- *subject* — предмет, по которому выполнен тест (строка);
- *score* — полученный балл (вещественное число);
- *cheat_flag* — подозрение на списывание (True/False);
- *attempt_no* — номер попытки (целое число, 1 означает первую попытку).

Выполните следующие действия с данными:

1. Очистите столбец *score*: пустые значения замените на 0, значения меньше 0 также замените на 0, значения больше 100 замените на 100.
2. Удалите строки, где *cheat_flag* = True.
3. Оставьте только строки, соответствующие первой попытке, то есть те, где *attempt_no* = 1.
4. Для каждого ученика вычислите его средний балл по предметам — это среднее всех значений *score*, которые остались после действий выше.

Сколько учеников имеют средний балл в диапазоне $60 \leqslant \text{avg\_score} < 80$?

**Что сдаётся:** одно целое число — количество таких учеников.

**Данные для занятия:** [tests_train.csv](tests_train.csv) — придуманный учебный набор из 18 строк с теми же пятью столбцами. Это не официальный файл и не отдельная модификация условия: правила обработки полностью совпадают с оригиналом. ## Простое объяснение

Представь электронный журнал: у каждого ученика несколько строк с работами по разным предметам. Сначала исправляем ошибочные баллы и убираем неподходящие попытки. Затем собираем оставшиеся работы каждого ученика вместе и вычисляем его средний балл.

Например, у ученика 101 после отбора остались оценки 50 и 70. Его средний балл:

$$
\frac{50 + 70}{2} = 60.
$$

Этот ученик подходит: 60 входит в диапазон. Ученик со средним ровно 80 уже не подходит. Ответ считает учеников, а не отдельные работы.

Готовый рабочий пример — [example.py](example.py). Знакомые чтение CSV, заполнение пропусков и фильтры сохранены. Новые операции:

- `clip(0, 100)` заменяет баллы вне границ самими границами: отрицательные становятся нулём, больше 100 — сотней. Строки не удаляются.
- `groupby("student_id")["score"].mean()` находит средний балл отдельно для каждого ученика. Слева в результате стоит номер ученика, справа — его средний балл.

Пример печатает очищенную таблицу, средние значения и подходящих учеников. На учебном файле после отбора остаются 12 работ; средние учеников 101–106 равны 60, 79.5, 80, 50, 35 и 70. Подходят 101, 102 и 106, итог — **3**. У учеников 107 и 108 не осталось допустимых работ, поэтому их нет в таблице средних.

### Как это будет на платформе

В исходной задаче участник скачивает таблицу в одном из предложенных форматов, обрабатывает её и вводит одно целое число. Программа и CSV вместо числа не загружаются.

Для перехода с учебного файла на официальный CSV нужно заменить имя `tests_train.csv` в программе на имя скачанного файла и проверить разделитель, заголовок и кодировку. Промежуточные `print()` можно оставить для собственной проверки: в поле ответа переносится только итоговое число. Учебный ответ 3 относится исключительно к маленькому файлу.
