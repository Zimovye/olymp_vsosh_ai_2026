# Учебная модификация. Пробуждение каменных големов

## Условие задачи

**Это придуманная учебная задача, а не официальный вариант олимпиады.** Основа — группа II, № 4 «Мониторинг энергопотребления магазина» муниципального этапа ВсОШ по ИИ 2025/26: [исходный разбор](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа2_Текстовый_разбор.pdf>), с. 3–4. Сохраняются разности, оба скользящих средних, медиана, часы наблюдения и правила тревог из предыдущей учебной модификации.

**Одно новое существенное изменение:** вместо одного ряда показаний нужно обработать несколько независимых рядов в общем CSV. Для каждого голема вычисления выполняются отдельно. Работа с группами объектов опирается на уже изученную группу III, № 4 «Group By»: [разбор](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf>), с. 2–3. Это учебное сочетание знакомых способов, а не обещание такого задания в будущем туре.

Каменные големы охраняют подземные ворота старого королевства. Перед пробуждением заряд их сердечных рун начинает расти. Хранитель должен отдельно следить за каждым големом: заряд одного не влияет на состояние другого.

В файле [golems.csv](golems.csv) находятся 720 записей с тремя столбцами:

- *golem_id* — положительный целый номер голема;
- *t* — номер измерения, начиная с 0;
- *charge* — заряд руны в условных единицах.

В файле три голема. У каждого есть ровно 240 измерений с номерами от 0 до 239, без пропусков и повторов. Измерения выполняются через каждые 15 минут, начало наблюдений — полночь. Строки файла упорядочены по *t*, но при одном и том же *t* записи разных големов могут стоять в любом порядке. Кодировка UTF-8, разделитель — запятая.

Для голема $g$ обозначим через $x_{g,t}$ его заряд в момент $t$. Определим изменение заряда:

$$
d_{g,t}=x_{g,t}-x_{g,t-1},
\qquad t\geqslant1.
$$

Средние вычисляются по окнам, заканчивающимся текущим измерением **того же голема**:

$$
\mathrm{ma}_{8,g}[t]=\frac{1}{8}\sum_{j=0}^{7}x_{g,t-j},
\qquad t\geqslant7;
$$

$$
\mathrm{ma\_diff}_{4,g}[t]=\frac{1}{4}\sum_{j=0}^{3}d_{g,t-j},
\qquad t\geqslant4.
$$

Через $\mathrm{med}_g$ обозначим медиану всех 240 исходных значений заряда голема $g$. При чётном количестве значений медиана равна среднему двух центральных после упорядочивания.

Момент $t$ опасен **для голема $g$**, если одновременно выполнены условия:

$$
\mathrm{ma\_diff}_{4,g}[t]\geqslant3,
\qquad \mathrm{ma}_{8,g}[t]\geqslant\mathrm{med}_g,
\qquad 36\leqslant(t\bmod96)\leqslant84.
$$

Последнее условие соответствует времени с 09:00 до 21:00 включительно. Пока полное окно не набралось, момент не считается опасным. Окна вычисляются по всем показаниям данного голема, включая ночные; при переходе к следующим суткам окна не начинаются заново.

Для каждого голема отдельно найдём максимально длинные серии подряд идущих опасных моментов $a,a+1,\ldots,b$. Неподходящий момент разрывает серию. Серия считается **одной тревогой**, если её длина

$$
L=b-a+1\geqslant3.
$$

Более короткие серии не учитываются. Серия, дошедшая до последнего измерения голема, учитывается по тем же правилам.

**Для каждого голема определите количество тревог и начало, конец и длину его самой длинной тревоги.** При равной длине выбирайте более раннюю тревогу этого голема.

### Формат ответа

Для каждого номера голема, встречающегося в исходном CSV, выведите одну строку. Строки расположите по возрастанию номера голема.

В каждой строке пять целых чисел через пробел:

1. Номер голема.
2. Количество его тревог.
3. Номер первого измерения выбранной тревоги.
4. Номер последнего измерения выбранной тревоги.
5. Длина выбранной тревоги в количестве измерений.

Если у голема нет тревог, после его номера выведите четыре нуля. Например, для голема 8 без тревог строка выглядела бы так:

```text
8 0 0 0 0
```

Големы без тревог должны присутствовать в ответе. Заголовки и поясняющие слова в итоговый ответ не включаются.

**Что сдаётся в этой учебной задаче:** три строки отчёта по описанному формату. Решение пиши в [answer.py](answer.py). Готового решения здесь нет; использовать предыдущие образцы разрешено.

## Простое объяснение

Раньше мы следили за одним уровнем воды. Теперь в одной таблице записаны три независимых голема. У каждого своя история заряда, своя медиана и свои тревоги.

Например, пусть заряд одного голема вырос с 80 до 85, а другого — с 900 до 906. Их изменения равны 5 и 6 соответственно. Разность между 900 и 80 здесь ничего не говорит о росте заряда: это показания разных големов.

Все знакомые правила серий остаются прежними. Если у одного голема опасны моменты 40, 41 и 42, это одна тревога длиной 3 независимо от того, какие записи другого голема стоят между ними в CSV.
