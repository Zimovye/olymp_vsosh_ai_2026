# Учебная модификация. Цветение садов друидов

## Условие задачи

**Это придуманная учебная задача, а не официальный вариант олимпиады.** Основа — группа II, № 4 «Мониторинг энергопотребления магазина» муниципального этапа ВсОШ по ИИ 2025/26: [разбор](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа2_Текстовый_разбор.pdf>), с. 3–4. Сохраняются разности, оба скользящих средних, отдельная медиана каждого объекта, часы наблюдения и правило объединения эпизодов из учебного варианта про колокола.

**Одно новое существенное изменение:** лучший эпизод выбирается по суммарной силе цветения, а не по числу активных измерений. Выбор по вычисленной характеристике связан с уже изученной [школьной задачей № 4 сезона 2026/27](../../../../../2026-2027/школьный_этап_2026_2027/Исходные_задачи/4.png): там после объединения наблюдений нужно было подсчитать визиты и выбрать лучший объект. Конкретная сумма $S$ придумана для этого упражнения.

В садах друидов растут зачарованные растения. Во время сильного цветения над грядками поднимаются светящиеся облака пыльцы. Друиды наблюдают за каждым садом отдельно и хотят выбрать наиболее сильный эпизод цветения.

В файле [gardens.csv](gardens.csv) находятся 720 записей:

- *garden_id* — положительный целый номер сада;
- *t* — номер измерения, начиная с 0;
- *bloom* — уровень цветения, неотрицательное целое число в условных единицах.

Всего три сада. Для каждого есть ровно 240 измерений с номерами от 0 до 239 без пропусков и повторов. Измерения выполняются каждые 15 минут, начало наблюдений — полночь. Файл упорядочен по *t*; записи разных садов при одном *t* могут стоять в любом порядке. Кодировка UTF-8, разделитель — запятая.

Для сада $g$ обозначим уровень цветения в момент $t$ через $x_{g,t}$. Все вычисления ниже выполняются **отдельно для каждого сада**.

Изменение уровня цветения:

$$
d_{g,t}=x_{g,t}-x_{g,t-1},
\qquad t\geqslant1.
$$

Скользящие средние по окнам, заканчивающимся текущим моментом:

$$
\mathrm{ma}_{8,g}[t]=\frac{1}{8}\sum_{j=0}^{7}x_{g,t-j},
\qquad t\geqslant7;
$$

$$
\mathrm{ma\_diff}_{4,g}[t]=\frac{1}{4}\sum_{j=0}^{3}d_{g,t-j},
\qquad t\geqslant4.
$$

Через $\mathrm{med}_g$ обозначим медиану всех 240 исходных значений уровня цветения этого сада. При чётном количестве значений медиана равна среднему двух центральных после упорядочивания.

Момент $t$ назовём активным для сада $g$, если одновременно выполнены условия:

$$
\mathrm{ma\_diff}_{4,g}[t]\geqslant3,
\qquad\mathrm{ma}_{8,g}[t]\geqslant\mathrm{med}_g,
\qquad36\leqslant(t\bmod96)\leqslant84.
$$

Последнее условие соответствует времени с 09:00 до 21:00 включительно. Пока нет полного окна, момент не считается активным. Окна вычисляются по всем показаниям данного сада, включая ночные, и не начинаются заново на границе суток.

### Эпизоды цветения

Активные моменты каждого сада рассматриваются по возрастанию времени. Два соседних активных момента относятся к одному эпизоду, если разность их номеров не больше двух. Эпизод максимален: в него включаются все активные моменты, которые можно последовательно присоединить по этому правилу.

Один неактивный момент между активными разрешён; два или больше подряд разделяют эпизоды. Одиночных промежутков внутри эпизода может быть несколько. Начало и конец эпизода — первый и последний активные моменты, а не неактивные моменты рядом с ними.

Пусть эпизод содержит активные моменты

$$
u_1<u_2<\ldots<u_K.
$$

В отчёт включаются только эпизоды с $K\geqslant3$. Число $K$ считает **только активные измерения**; неактивные моменты в промежутках его не увеличивают. Эпизод в конце файла учитывается по тем же правилам.

### Сила эпизода

Для каждого активного момента определим вклад:

$$
w_{g,t}=x_{g,t}-x_{g,t-4}
=4\,\mathrm{ma\_diff}_{4,g}[t].
$$

**Сила эпизода** — сумма вкладов всех его активных моментов:

$$
S=\sum_{i=1}^{K}w_{g,u_i}.
$$

Неактивные моменты внутри эпизода в эту сумму не входят. Поскольку исходные уровни целые, каждый вклад и сила $S$ — целые числа.

Для каждого сада найдите количество эпизодов с $K\geqslant3$ и выберите среди них эпизод с **наибольшей силой $S$**. При равенстве $S$ выбирается более ранний эпизод. Число активных измерений не используется как дополнительный критерий при равенстве силы.

### Формат ответа

Для каждого сада из исходного CSV выведите одну строку по возрастанию *garden_id*. В строке шесть целых чисел через пробел:

1. Номер сада.
2. Количество эпизодов, содержащих не менее трёх активных измерений.
3. Номер первого активного измерения выбранного эпизода.
4. Номер последнего активного измерения выбранного эпизода.
5. Число активных измерений $K$ в выбранном эпизоде.
6. Сила $S$ выбранного эпизода.

Если подходящих эпизодов нет, после номера сада выведите пять нулей. Такие сады не должны исчезать из отчёта. Итог — три строки без заголовков и поясняющих слов.

**Что сдаётся в этой учебной задаче:** указанные три строки чисел. Решение пиши в [answer.py](answer.py). Готового решения и контрольного ответа в папке нет. Предыдущие образцы использовать разрешено.

## Простое объяснение

Эпизоды объединяются точно так же, как в задаче про колокола. Изменяется выбор лучшего: теперь учитываем, насколько сильным был рост, а не только сколько активных измерений набралось.

Например, пусть после всех проверок у сада 8 осталось два подходящих эпизода:

- моменты 40, 41, 43 и 44 со вкладами 12, 12, 12 и 12;
- моменты 50, 51 и 53 со вкладами 20, 20 и 20.

У первого эпизода четыре активных измерения, но его сила равна

$$
12+12+12+12=48.
$$

У второго только три активных измерения, зато сила равна

$$
20+20+20=60.
$$

Выбираем второй. **Только для этого поясняющего примера** строка ответа была бы:

```text
8 2 50 53 3 60
```

Это не ответ на `gardens.csv`. Вклады в этом примере уже заданы; для полного файла их нужно вычислить из показаний.

### Как это будет на платформе

Это домашняя учебная модификация. Данные находятся в `gardens.csv`, решение — обычный `.py`, результат — три строки по шесть целых чисел. Промежуточные выводы разрешены для разбора; для итогового формата оставь только строки отчёта.
