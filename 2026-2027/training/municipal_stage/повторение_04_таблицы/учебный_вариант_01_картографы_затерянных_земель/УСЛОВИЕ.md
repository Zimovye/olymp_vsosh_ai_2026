# Учебная модификация № 1. Картографы затерянных земель

## Условие задачи

**Это учебная смесь задач № 4 групп I и III, а не официальное задание.**

Королевство собирает атлас затерянных земель. Требуется определить, сколько картографов каждой гильдии выполнили условия допуска к составлению атласа.

Даны два файла CSV. Кодировка — UTF-8, разделитель — запятая, первая строка содержит имена столбцов. Пустая ячейка означает пропуск. Строки в файлах не упорядочены.

**Журнал проверок — [surveys.csv](surveys.csv):**

| Столбец | Содержание |
|---|---|
| `map_id` | Номер карты |
| `cartographer_id` | Номер её автора |
| `hours` | Число часов, затраченных на подготовку карты |
| `terrain` | Тип местности: строка или пропуск |
| `score` | Оценка проверяющего: число или пропуск |
| `forged` | Признак подделки: `True` или `False` |
| `attempt_no` | Номер попытки проверки этой карты; 1 означает первую попытку |

Одна строка — одна попытка проверки одной карты. У каждой карты ровно один автор; пара из номера карты и номера попытки не повторяется. У одного картографа может быть несколько карт одной местности.

**Реестр — [cartographers.csv](cartographers.csv):**

| Столбец | Содержание |
|---|---|
| `cartographer_id` | Номер картографа |
| `guild_id` | Номер гильдии, к которой он принадлежит |

В реестре каждый картограф записан ровно один раз. Все авторы из журнала присутствуют в реестре. Принадлежность к гильдии определяется только реестром.

Выполните действия в указанном порядке.

1. Оставьте в журнале только первые попытки без признака подделки, для которых время подготовки $h$ удовлетворяет условию

   $$1 \leqslant h \leqslant 96.$$

   Если первая попытка не подходит, вторая её не заменяет.

2. В оставшихся строках замените пропуски оценки на 0. Оценки меньше 0 замените на 0, больше 100 — на 100. Обозначим исправленную оценку через $q$.

3. Среди непустых значений местности **всего оставшегося журнала** найдите моду — наиболее частое значение. Заполните ею пропуски местности. Назовём эту местность основной.

4. Среди всех строк после шагов 1–3 найдите минимальную и максимальную исправленные оценки $q_{\min}$ и $q_{\max}$. Для каждой строки вычислите нормированную оценку

   $$z=\frac{q-q_{\min}}{q_{\max}-q_{\min}}.$$

   Границы общие для всего оставшегося журнала, а не отдельные для каждого автора или гильдии.

5. Для дальнейшего расчёта оставьте только карты основной местности, подготовленные не более чем за 48 часов.

6. Для каждого картографа найдите количество оставшихся карт $n$ и среднее их нормированных оценок

   $$\overline z=\frac{z_1+z_2+\ldots+z_n}{n}.$$

   Картограф получает допуск, если одновременно

   $$n\geqslant 3,\qquad 0{,}6\leqslant\overline z<0{,}8.$$

   Если карт не осталось, картограф допуск не получает. Среднее до сравнения не округляйте.

7. По реестру определите гильдию каждого картографа. Для **каждой гильдии из реестра** посчитайте число её картографов с допуском. Каждый человек учитывается один раз независимо от числа его карт.

Гарантируется, что после шага 1 журнал не пуст, среди непустых местностей есть единственная мода, а после исправления оценок $q_{\min}<q_{\max}$. Других пропусков, кроме указанных для местности и оценки, нет.

**Что сдаётся:** текстовый отчёт. Для каждой гильдии выведите в отдельной строке два целых числа: её номер и число картографов с допуском. Строки расположите по возрастанию номера гильдии. Гильдию без допущенных картографов тоже включите с числом 0. Заголовок и пояснения в ответ не входят.

## Простое объяснение

Первый файл сообщает, какие карты сделал каждый человек и как их оценили. Второй сообщает, в какой гильдии состоит этот человек. Записи связывает **номер картографа**: одинаковая позиция строк в двух файлах ничего не означает.

Сначала очищаем журнал и приводим оценки к общей шкале. Затем отбираем нужные карты, считаем количество и среднее отдельно для каждого автора. В конце относим подходящих авторов к их гильдиям.

Например, у картографа 42 после всех отборов остались три карты с нормированными оценками $0{,}65$, $0{,}70$ и $0{,}75$. Среднее равно $0{,}70$, поэтому он получает допуск. Если реестр относит его к гильдии 9, её итог увеличивается на одного человека. Это отдельный пример, а не фрагмент ответа к файлам.

**Что меняется относительно знакомых задач:** сведения о результатах и гильдиях находятся в разных таблицах. Нужно связать их по общему номеру и сохранить в отчёте гильдии с нулевым результатом. Очистка, мода, нормализация, фильтры и средние остаются частью задачи.

**Основа:** муниципальные задания ВсОШ по ИИ 2025/26 для 9–11 классов: `МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf`, № 4, с. 3–4 — отбор, заполнение модой, нормализация; `МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf`, № 4, с. 2–3 — исправление оценок, отбор первых попыток и групповые средние. Объединение с отдельным реестром добавлено для учебной практики; это не подтверждённое содержание будущего тура. Данные в обоих CSV придуманы.

### Как это будет на платформе

В этом учебном варианте ты получаешь два CSV и вычисляешь по ним текстовый отчёт. Работаешь в [answer.py](answer.py); сейчас в нём только чтение файлов и показ нескольких строк. Для проверки решения присылай этот файл. Готового решения и контрольного отчёта здесь нет.

В исходных задачах № 4 муниципального этапа 2025/26 участник скачивал таблицу и вводил одно число. Здесь формат намеренно изменён: требуется несколько строк с результатами по гильдиям. При подготовке учебного отчёта отдели его от промежуточных `print()`; программа и исходные CSV не заменяют сам отчёт. Формат реального муниципального этапа 2026/27 нужно смотреть в его условии.
