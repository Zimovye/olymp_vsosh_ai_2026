# Учебная модификация № 1. Руны горного рудника

## Условие задачи

Это придуманная учебная модификация, не официальная задача олимпиады.

Основа: группа I, № 5 «Сжатие размерности», муниципальный этап ВсОШ по ИИ 2025/26, 9–11 классы; [исходный PDF](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf>), с. 4–5. Сохраняются десять бинарных признаков, формат чисел и удаление постоянных столбцов. Добавлено одно правило: среди оставшихся одинаковых столбцов сохраняется только один. Теперь требуется также вывести номера сохранённых признаков. Это учебное изменение обработки той же таблицы, не прогноз варианта 2026/27.

Гномы исследуют $n$ кристаллов из горного рудника. На каждом кристалле есть десять позиций для рун. Руна может светиться (1) или быть погасшей (0).

Состояние каждого кристалла записано целым числом $a_i$. Его двоичная запись дополняется нулями слева до длины 10. Позиции рун нумеруются слева направо, от 1 до 10. Получается таблица: строки — кристаллы, столбцы — позиции рун.

Чтобы сократить описание кристаллов, гномы применяют два правила по порядку:

1. Удаляют каждый столбец, в котором у всех кристаллов одно значение: только 0 или только 1.
2. Среди оставшихся столбцов находят одинаковые. Два столбца одинаковы, если их значения совпадают для каждого кристалла. Из каждой группы одинаковых столбцов оставляют только столбец с наименьшим исходным номером.

Найдите количество оставшихся столбцов и их исходные номера в порядке возрастания. После удаления столбцов номера не меняются.

**Формат входных данных**

В первой строке дано число $n$ ($1 \leq n \leq 1000$).

В следующих $n$ строках дано по одному целому числу $a_i$ ($0 \leq a_i < 1024$).

**Формат выходных данных**

Выведите в одной строке сначала количество оставшихся столбцов, затем через пробел их исходные номера в порядке возрастания.

Если ни одного столбца не осталось, выведите одно число 0.

**Пример 1**

Ввод:

```text
3
0
3
12
```

Вывод:

```text
2 7 9
```

**Пример 2**

Ввод:

```text
2
7
7
```

Вывод:

```text
0
```

## Простое объяснение

Сначала выполняем знакомое действие: оставляем позиции, в которых у разных кристаллов встречаются и 0, и 1.

Теперь добавилась проверка повторов. Если две руны у каждого кристалла одновременно светятся или одновременно погашены, их столбцы повторяют друг друга. Достаточно оставить один из них — с меньшим номером. Сравниваются значения у одних и тех же кристаллов: совпасть должны все строки.

В ответе сообщаем, сколько позиций осталось, и перечисляем их исходные номера. Это позволит проверить, какие именно столбцы ты сохранил.

**Как это будет на платформе**

Это домашнее упражнение без страницы в официальном туре. Для учебной проверки сохраняй программу в обычном `answer.py`: вход — число $n$ и затем $n$ обычных целых чисел; выход — одна строка с количеством и номерами оставшихся столбцов либо 0. Во время решения можно печатать промежуточные значения; при подготовке к проверке оставить только требуемый результат.

В исходной официальной задаче 2025/26 удаляются только постоянные столбцы и выводится только их оставшееся количество. Точные условия площадки муниципального этапа 2026/27 ещё не подтверждены.
