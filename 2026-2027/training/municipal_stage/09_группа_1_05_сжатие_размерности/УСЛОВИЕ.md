# Группа I, № 5. Сжатие размерности

## Условие задачи

Оригинальная задача муниципального этапа ВсОШ по ИИ 2025/26 для 9–11 классов, вариант I. Девятая задача в согласованном порядке подготовки.

Источник: [МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf](<../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf>), с. 4 — полное условие и начало разбора, с. 5 — продолжение разбора и код на C++. [Официальная страница архива](https://siriusolymp.ru/2025/municipal/ai).

Ограничение по времени: 1 секунда.

Ограничение по памяти: 256 мегабайт.

В машинном обучении часто возникает проблема: данных слишком много, а ресурсов слишком мало. Например, вы обучаете модель для распознавания изображений, и каждое изображение описывается миллионом признаков (по числу пикселей). Если хранить и обрабатывать все признаки, модель получится очень тяжёлой и будет работать медленно.

Чтобы справиться с этим, используют приём сжатия размерности. Его смысл — это удалить или преобразовать те признаки, которые не дают новой информации. Например:

- если у всех объектов один и тот же цвет фона, то этот признак можно убрать;
- если признак не меняется, он не помогает отличать объекты друг от друга.

Рассмотрим упрощённый вариант этой идеи.

Дана выборка объектов $a$, состоящая из $n$ элементов $a_i$. Каждый объект $a_i$ представляется двоичной строкой длины 10. Получается таблица признаков: строки — объекты, столбцы — признаки (первый бит — первый признак, второй бит — второй признак и так далее). Все признаки бинарные: каждый бит равен либо 0, либо 1.

Если какой-то признак одинаков у всех чисел, он не несёт информации и должен быть удалён.

Сколько признаков останется после удаления одинаковых?

**Формат входных данных**

В первой строке входных данных даётся одно число $n$ ($1 \leq n \leq 1000$) — количество объектов в выборке $a$.

В следующих $n$ строках даётся по одному целому числу $a_i$ ($0 \leq a_i < 1024$) — битовые представления объектов.

**Формат выходных данных**

Выведите одно целое число — количество оставшихся после удаления признаков.

**Пример**

Стандартный ввод:

```text
3
741
121
164
```

Стандартный вывод:

```text
7
```

**Замечание**

В первом тестовом примере в массиве $a$ было всего 3 числа: 741, 121, 164. В двоичном виде они выглядят как $1011100101$, $0001111001$, $0010100100$. Удалены будут 2-й, 5-й и 9-й признаки. Останется 7 признаков.

Максимальный балл за задание в исходном комплекте 2025/26 — 100. Это исторические сведения об этой задаче, а не подтверждённая шкала муниципального этапа 2026/27.

## Простое объяснение

Признак — это одна характеристика объекта. Бинарный признак имеет два значения: 0 и 1. Размерность здесь — число признаков, то есть столбцов таблицы. Представь анкеты с десятью вопросами «да/нет»: каждая анкета — строка, каждый вопрос — столбец. Если все ответили на вопрос одинаково, такой столбец удаляем. Если встречаются оба ответа, оставляем.

Во входе эти десять ответов записаны одним обычным целым числом. В программе мы получим его двоичную запись: строку из десяти нулей и единиц. Нули слева нужны, чтобы у всех объектов было ровно десять позиций. Признаки в объяснении нумеруются слева направо, от 1 до 10; индексы строк в Python начинаются с 0.

**Маленький готовый пример — учебные данные**

Введи в `example.py`:

```text
3
4
5
12
```

Получатся такие строки:

| Число на входе | Двоичная строка из 10 символов |
|---:|:---|
| 4 | $0000000100$ |
| 5 | $0000000101$ |
| 12 | $0000001100$ |

Меняются только 7-й и 10-й признаки, поэтому учебный ответ — 2. В 8-м столбце у всех единица, поэтому этот столбец тоже удаляется.

В `example.py` показан один способ из авторского объяснения: сравнивать каждый столбец со значением у первого объекта. Как только найдено отличие, этот признак точно остаётся и можно закончить просмотр его столбца. Для следующего признака проверка начинается заново. При заданных ограничениях получается не больше $10n \leq 10\,000$ сравнений символов.

Код показывает двоичные записи первых трёх объектов и решение по каждому из десяти признаков. Полный набор не печатается. Функция `format(number, "010b")` создаёт нужную двоичную строку; для неё добавлена локальная подсказка.

**Как это будет на платформе**

В исходной задаче 2025/26 это программное задание. Программа получает число $n$, затем $n$ обычных целых чисел через стандартный ввод. Двоичные строки участник получает в своей программе; скачиваемой таблицы нет.

Для нашей практики используется Python 3 и обычный `.py`. Отправляется программа, которая для любого допустимого входа выводит одно целое число — количество оставшихся признаков. Перед сдачей убрать промежуточные `print()` вместе с ветками, нужными только для печати, а последнюю строку заменить на `print(answer)`. Чтение входных данных и вычисления сохранить.

Точные условия площадки муниципального этапа 2026/27 ещё не подтверждены; школьные правила отправок автоматически сюда не переносим.
