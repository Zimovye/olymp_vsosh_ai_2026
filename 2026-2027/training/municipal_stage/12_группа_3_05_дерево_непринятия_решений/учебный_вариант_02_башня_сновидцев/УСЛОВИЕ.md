# Учебная модификация № 2. Башня сновидцев

## Условие задачи

Это придуманная учебная модификация, не официальная задача олимпиады.

Основа: группа III, № 5 «Дерево непринятия решений», муниципальный этап ВсОШ по ИИ 2025/26, 9–11 классы; [исходный PDF](<../../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf>), с. 3–5. В исходном условии описано полное бинарное дерево глубины $n$, а конкретная задача использует глубину 3. Здесь глубина становится входным параметром. Сохраняются переходы по нумерованным вершинам, произведения вероятностей и знакомое по модификации № 1 объединение одинаковых конечных результатов. Это учебное изменение размера дерева, не прогноз варианта 2026/27.

В башне сновидцев путник проходит ровно $n$ последовательных развилок сна. На каждой развилке есть два направления: налево (0) и направо (1). В конце пути он видит одно видение с заданным номером. Разные пути могут заканчиваться одинаковым видением.

Маршруты образуют полное бинарное дерево глубины $n$:

- корень имеет номер 1;
- у внутренней вершины $v$ левый ребёнок имеет номер $2v$, правый — $2v+1$;
- внутренние вершины имеют номера от 1 до $2^n-1$;
- каждый маршрут записывается двоичной строкой длины $n$;
- всего маршрутов $2^n$.

Для каждой внутренней вершины $v$ задано целое число $p_v$: вероятность пойти налево в процентах. Вероятность пойти направо равна $100-p_v$ процентов. Вероятность маршрута равна произведению вероятностей всех его выборов.

Найдите общую вероятность каждого видения, указанного во входных данных. Представляйте её в виде

$$
P(\text{видение }d)=\frac{W_d}{100^n}.
$$

В ответе требуется вывести целый числитель $W_d$. Все указанные видения должны присутствовать в ответе, включая видения с нулевой вероятностью.

Упорядочите видения по неубыванию общей вероятности, а при равенстве — по возрастанию номера видения.

**Формат входных данных**

В первой строке задано целое число $n$ ($1 \leq n \leq 8$) — глубина дерева.

Во второй строке заданы $2^n-1$ целых чисел $p_1,p_2,\ldots,p_{2^n-1}$ ($0 \leq p_v \leq 100$) в порядке номеров внутренних вершин.

В третьей строке заданы $2^n$ целых чисел $d_1,d_2,\ldots,d_{2^n}$ ($1 \leq d_i \leq 1000$) — номера конечных видений. Они перечислены в лексикографическом порядке кодов маршрутов длины $n$.

Например, для $n=1$ порядок кодов — `0`, `1`; для $n=2$ — `00`, `01`, `10`, `11`.

**Формат выходных данных**

В первой строке выведите количество различных видений, указанных во входе.

Затем для каждого такого видения выведите отдельную строку с двумя целыми числами через пробел: номер видения $d$ и числитель его общей вероятности $W_d$ при знаменателе $100^n$.

Строки должны идти по возрастанию $W_d$, а при равенстве — по возрастанию номера видения. Каждое видение выводится ровно один раз.

**Пример 1**

Ввод:

```text
2
50 20 80
4 9 4 9
```

Вывод:

```text
2
4 5000
9 5000
```

**Пример 2**

Ввод:

```text
1
0
7 11
```

Вывод:

```text
2
7 0
11 100
```

## Простое объяснение

Глубина $n$ показывает, сколько выборов делает путник за один сон. После каждого выбора к коду добавляется одна цифра, поэтому длина готового кода равна $n$. В разных входных данных будет разное число развилок и конечных маршрутов.

Вероятности путей, заканчивающихся одним видением, по-прежнему учитываются вместе. Общий знаменатель теперь равен $100^n$: например, при двух выборах это 10000, при одном — 100. В ответе указываем только числители и номера видений.

**Как это будет на платформе**

Это домашнее упражнение без страницы в официальном туре. Для учебной проверки сохраняй программу в обычном `answer.py`: вход — три строки с глубиной, вероятностями и номерами видений; выход — количество различных видений и затем строки «номер, числитель» в требуемом порядке. Во время решения можно печатать промежуточные значения; при подготовке к проверке оставить только требуемый результат.

В исходной официальной задаче 2025/26 глубина всегда равна 3, на входе только семь вероятностей, а на выходе восемь кодов маршрутов. Точные условия площадки муниципального этапа 2026/27 ещё не подтверждены.
