# Учебная модификация группы III, № 2. Два режима

## Условие задачи

**Авторская учебная модификация для самостоятельного решения.** Основа — муниципальный этап ВсОШ по искусственному интеллекту 2025/26, группа III, № 2 «Максимальный след по всем перестановкам»: `МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf`, страницы 1–2. [Полное исходное условие](../УСЛОВИЕ.md). В этой модификации меняется цель оптимизации: одна настройка должна работать в двух режимах.

Модуль распознавания речи проверяют в дневном и ночном режимах. Настройку модуля задаёт матрица

```text
B = (x y)
    (z w)
```

В её четыре клетки нужно расставить числа **−2, 1, 3, 6**, используя каждое ровно один раз. Рассматриваются все 24 расстановки.

Матрицы двух режимов фиксированы:

```text
A_день = (1 4)       A_ночь = (4 1)
         (2 3)                (3 2)
```

Для выбранной настройки B вычисляют два балла:

- дневной: `S_день = tr(A_день * B)`;
- ночной: `S_ночь = tr(A_ночь * B)`.

Здесь произведение — обычное умножение матриц по правилу «строка на столбец», а след `tr` — сумма верхнего левого и нижнего правого элементов. В частности, если

```text
A = (a b)       B = (x y)
    (c d)           (z w)
```

то `tr(A * B) = (a * x + b * z) + (c * y + d * w)`.

**Гарантированный балл настройки** равен меньшему из её двух баллов: `G = min(S_день, S_ночь)`.

Матрица B должна быть **одной и той же для обоих режимов**. Менять расстановку при переходе из дня в ночь нельзя.

Найдите:

**а)** Наибольший возможный гарантированный балл G.

**б)** Количество различных матриц B, для которых достигается этот наибольший G.

Две матрицы B считаются разными, если различаются значения хотя бы в одной клетке. Матрицы с одинаковыми баллами, но разными расстановками учитываются отдельно.

**Что сдаётся:** два целых числа через пробел: сначала ответ а), затем ответ б).

## Простое объяснение

Представь устройство, которое должно хорошо работать и днём, и ночью. Для каждой расстановки есть две оценки, а надёжность определяют по худшей из них. Нужно выбрать настройку с самой высокой худшей оценкой и посчитать, сколько настроек дают такой результат.

Например, у матрицы B с верхней строкой `−2, 1` и нижней строкой `3, 6` дневной балл равен 30, ночной — 10. Её гарантированный балл равен 10. Это пример понимания критерия, а не итоговый ответ.

Решение напиши в соседнем `answer.py`. Предыдущий образец можно использовать; готового решения этой модификации здесь нет.

**Как это будет на платформе**

В этой учебной имитации обе матрицы режимов и четыре числа даны в условии; скачивать данные не нужно. В поле ответа вводятся два целых числа в указанном порядке, без подписей. Дома сохрани программу в `answer.py` и сообщи её результат в чате. Промежуточные `print()` можно оставить: в поле переносятся только два итоговых числа. Это формат данного учебного варианта.
