# Учебная модификация группы III, № 2. Два критерия

## Условие задачи

**Авторская учебная модификация для самостоятельного решения.** Основа — муниципальный этап ВсОШ по искусственному интеллекту 2025/26, группа III, № 2 «Максимальный след по всем перестановкам»: `МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf`, страницы 1–2. [Полное исходное условие](../УСЛОВИЕ.md). Развиваем освоенную модификацию «Два режима»: добавляется правило выбора среди настроек с одинаковым гарантированным баллом.

Модуль распознавания речи проверяют днём и ночью. Его настройка задаётся матрицей

```text
B = (u v)
    (w x)
```

В четыре клетки нужно расставить числа **−2, 1, 3, 6**, используя каждое ровно один раз. Одна и та же матрица B используется в обоих режимах.

Матрицы режимов:

```text
A_день = (1 4)       A_ночь = (5 4)
         (2 3)                (3 1)
```

Баллы настройки:

- `S_день = tr(A_день * B)`;
- `S_ночь = tr(A_ночь * B)`.

Произведение вычисляется по правилу «строка на столбец». След `tr` — сумма верхнего левого и нижнего правого элементов. Если

```text
A = (p q)       B = (u v)
    (r s)           (w x)
```

то `tr(A * B) = (p * u + q * w) + (r * v + s * x)`.

У настройки есть две характеристики:

- **гарантированный балл** `G = min(S_день, S_ночь)`;
- **общий балл** `T = S_день + S_ночь`.

Настройку выбирают в следующем порядке:

1. Сначала находят наибольший возможный G среди всех 24 матриц B.
2. Среди матриц с этим наибольшим G выбирают те, у которых T максимально.

**Приоритет у G.** Больший общий балл T не компенсирует меньший гарантированный балл.

Найдите:

**а)** Наибольший возможный G.

**б)** Наибольший T среди матриц, у которых G равен ответу а).

**в)** Количество матриц B, у которых одновременно G равен ответу а), а T равен ответу б).

Две матрицы B считаются разными, если различаются значения хотя бы в одной клетке. Разные расстановки с одинаковыми баллами учитываются отдельно.

**Что сдаётся:** три целых числа через пробел: ответы а), б), в) в указанном порядке.

## Простое объяснение

Представь отбор устройства для работы днём и ночью. Сначала важна надёжность в худшем режиме. Если по ней несколько настроек одинаково хороши, выбираем из них настройки с лучшей суммой двух оценок.

Например, для B с верхней строкой `−2, 1` и нижней строкой `3, 6` дневной балл равен 30, ночной — 11. Значит, у этой настройки G = 11 и T = 41. Это пример расчёта характеристик, а не итоговые ответы.

Решение напиши в соседнем `answer.py`. Использовать свои предыдущие решения разрешено; готового решения этой модификации здесь нет.

**Как это будет на платформе**

В этой учебной имитации все данные даны в условии, скачивать ничего не нужно. В поле ответа вводятся три целых числа через пробел в указанном порядке. Дома сохрани код в `answer.py` и сообщи его результат в чате. Промежуточные `print()` можно оставить: в поле переносятся только три итоговых числа. Это формат данного учебного варианта.
