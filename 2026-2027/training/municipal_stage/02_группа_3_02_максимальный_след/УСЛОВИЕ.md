# Группа III, № 2. Максимальный след по всем перестановкам

## Условие задачи

Источник: муниципальный этап ВсОШ по искусственному интеллекту 2025/26, вариант III, 9–11 классы; `МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf`, задание 2. Условие находится на странице 1, разбор — на страницах 1–2. Файл: `2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_3_Текстовый_разбор.pdf`.

Ниже полное исходное условие; матрицы и формулы записаны обычными символами.

Матрицей n × m будем называть таблицу из чисел, состоящую из n строк и m столбцов. Умножение матриц выполняют по правилу «строка на столбец». Если

```text
M = (p q)     N = (u v)
    (r s)         (w x)
```

то

```text
MN = (p*u + q*w   p*v + q*x)
     (r*u + s*w   r*v + s*x)
```

Суммой диагональных элементов (следом) матрицы называют число

```text
tr(p q) = p + s.
  (r s)
```

Дана матрица

```text
A = (-1  4)
    ( 5 10)
```

Также даны числа −4, −5, 20, 25. Рассматриваются все 24 матрицы B вида

```text
B = (x y)
    (z w)
```

в которых x, y, z, w — некоторая перестановка чисел −4, −5, 20, 25. Для каждой такой B рассмотрите произведения AB и BA.

**а)** Найдите наибольшее возможное значение tr(AB).

**б)** Найдите наибольшее возможное значение tr(BA).

**Что сдаётся:** численный ответ для каждого из двух подпунктов.

## Простое объяснение

Представь четыре карточки, которые раскладывают в четыре клетки на листе. Это матрица B; её числа можно переставлять. Матрица A остаётся неизменной. Для каждого расположения нужно выполнить вычисления по правилу умножения, взять верхний левый и нижний правый результаты и сложить их. Эта сумма называется следом.

Знакомый `permutations` снова перечислит 24 расположения. Теперь для каждого расположения получаем числовую оценку и ищем самую большую. `AB` означает A, умноженную на B; `BA` — B, умноженную на A. Эти два порядка рассматриваются отдельно.

**Готовый учебный пример с изменёнными данными**

Для первого запуска возьмём меньшие числа:

```text
A = (1 2)     B = (x y)
    (3 4)         (z w)

Числа для B: 1, 2, 3, 4, каждое используется ровно один раз.
```

Нужно найти максимумы tr(AB) и tr(BA) среди всех перестановок этих четырёх чисел. Это учебное изменение исходной задачи; готовый код сохранён в `example.py`, файл `answer.py` оставлен для твоей работы.

Начнём с B, в которой сверху стоят 1, 2, снизу — 3, 4:

- Верхний левый элемент AB: первая строка A на первый столбец B — `1 * 1 + 2 * 3 = 7`.
- Нижний правый элемент AB: вторая строка A на второй столбец B — `3 * 2 + 4 * 4 = 22`.
- След AB: `7 + 22 = 29`.

Для произвольной перестановки формулы этих двух клеток — `x + 2 * z` и `3 * y + 4 * w`. В коде они вычисляются по отдельности. Для BA так же получаются `x + 3 * y` и `2 * z + 4 * w`.

Сначала запусти `example.py` целиком и найди строку для B = `(1, 2, 3, 4)`: диагональные числа AB должны быть 7 и 22, след — 29. Программа сохраняет следы в небольших списках и через знакомый `max()` выбирает наибольшие. В выводе можно заметить, что при каждом расположении tr(AB) и tr(BA) равны — это также объясняется в официальном разборе.

**Как это будет на платформе**

Учебная программа помогает считать, её код в эту задачу не загружается, поэтому промежуточные `print()` можно сохранить.
