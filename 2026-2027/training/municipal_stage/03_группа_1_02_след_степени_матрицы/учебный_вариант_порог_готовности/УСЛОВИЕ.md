# Учебная модификация группы I, № 2. Порог готовности

## Условие задачи

**Авторская учебная модификация для самостоятельного решения.** Основа — муниципальный этап ВсОШ по искусственному интеллекту 2025/26, группа I, № 2 «След степени матрицы»: `МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf`, страницы 1–2. [Полное исходное условие и объяснение умножения](../УСЛОВИЕ.md).

Устройство выполняет одинаковые шаги обработки сигнала. Один шаг задаётся матрицей

```text
A = (1 1)
    (1 0)
```

После n шагов результат описывается матрицей A^n. Здесь A^1 = A, а A^(n+1) = A^n * A; используется обычное умножение матриц по правилу «строка на столбец».

Показатель готовности после n шагов равен **следу A^n** — сумме её верхнего левого и нижнего правого элементов.

Устройство готово к работе, когда показатель **не меньше 5000**.

Рассматриваются целые n **от 1 до 30 включительно**. Гарантируется, что в этом диапазоне устройство достигает готовности.

Найдите:

**а)** Наименьшее n, при котором устройство готово к работе.

**б)** Показатель готовности именно после этого количества шагов.

**Что сдаётся:** два целых числа через пробел: сначала n, затем след A^n для найденного n.

## Простое объяснение

Представь устройство с индикатором готовности. После каждого одинакового действия показание индикатора определяется текущей степенью матрицы. Нужно узнать, на каком шаге индикатор впервые достигнет нужной отметки, и записать его значение на этом шаге.

Например, после первого шага след равен 1, после второго — 3. Оба значения ещё меньше 5000. Требуется найти первый подходящий шаг в указанном диапазоне.

Решение напиши в соседнем `answer.py`. Свой исправленный код исходной задачи можно использовать как основу; готового решения этой модификации здесь нет.

**Как это будет на платформе**

В этой учебной имитации матрица, порог и диапазон степеней даны в условии; скачивать ничего не нужно. В поле ответа вводятся два целых числа в указанном порядке. Дома сохрани программу в `answer.py` и сообщи её результат в чате. Промежуточные `print()` можно оставить: в поле переносятся только два итоговых числа. Это формат данного учебного варианта.
