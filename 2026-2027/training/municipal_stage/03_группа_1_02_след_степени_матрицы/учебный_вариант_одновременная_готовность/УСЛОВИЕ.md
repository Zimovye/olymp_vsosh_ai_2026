# Учебная модификация группы I, № 2. Одновременная готовность

## Условие задачи

**Авторская учебная модификация для самостоятельного решения.** Основа — муниципальный этап ВсОШ по искусственному интеллекту 2025/26, группа I, № 2 «След степени матрицы»: `МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf`, страницы 1–2. [Полное исходное условие и объяснение степеней](../УСЛОВИЕ.md). Развиваем учебный вариант «Новый модуль»: теперь одновременно работают два устройства.

Первое устройство выполняет шаги с матрицей A, второе — с матрицей B:

```text
A = (2 1)       B = (3 1)
    (3 1)           (1 1)
```

После n шагов результат первого устройства описывается матрицей **A^n**, второго — матрицей **B^n**. Оба устройства выполняют одинаковое число шагов n.

Первая степень — сама исходная матрица. Каждая следующая получается по правилам A^(n+1) = A^n * A и B^(n+1) = B^n * B. Матрицы одного шага A и B остаются неизменными.

Умножение выполняется по правилу «строка на столбец»: если

```text
M = (p q)       N = (u v)
    (r s)           (w x)
```

то

```text
MN = (p*u + q*w   p*v + q*x)
     (r*u + s*w   r*v + s*x)
```

Показатель готовности каждого устройства — **след его текущей матрицы**, то есть сумма верхнего левого и нижнего правого элементов.

Система готова, когда **показатель каждого из двух устройств не меньше 5000**.

Рассматриваются целые n **от 1 до 30 включительно**. Гарантируется, что в этом диапазоне система достигает готовности.

Найдите:

**а)** Наименьшее n, при котором система готова.

**б)** Показатель первого устройства после найденных n шагов.

**в)** Показатель второго устройства после тех же n шагов.

Если какое-то устройство достигло порога раньше, оно продолжает выполнять шаги. В ответе нужны показатели обоих устройств **на одном общем шаге n**.

**Что сдаётся:** три целых числа через пробел: сначала n, затем след A^n, затем след B^n.

## Простое объяснение

Представь два прибора с индикаторами готовности. Они работают одновременно, но их показатели меняются по разным правилам. Нужно дождаться первого шага, на котором готовы оба, и записать оба показания именно на этом шаге.

После первого шага показатели равны 3 и 4, после второго — 11 и 12. Пока оба ниже нужной отметки. Если один прибор достигнет порога раньше другого, его показание к общему моменту готовности успеет измениться.

Решение напиши в соседнем `answer.py`. Свои предыдущие решения можно использовать; готового решения этой модификации здесь нет.

**Как это будет на платформе**

В этой учебной имитации обе матрицы, порог и диапазон степеней даны в условии; скачивать данные не нужно. В поле ответа вводятся три целых числа в указанном порядке. Дома сохрани программу в `answer.py` и сообщи её результат в чате. Промежуточные `print()` можно оставить: в поле переносятся только три итоговых числа. Это формат данного учебного варианта.
