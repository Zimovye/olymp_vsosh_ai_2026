# Учебная модификация группы I, № 2. Новый модуль

## Условие задачи

**Авторская учебная модификация для самостоятельного решения.** Основа — муниципальный этап ВсОШ по искусственному интеллекту 2025/26, группа I, № 2 «След степени матрицы»: `МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf`, страницы 1–2. [Полное исходное условие и объяснение степеней](../УСЛОВИЕ.md). Продолжаем учебный вариант «Порог готовности»; изменена матрица одного шага.

В устройство обработки сигнала установили новый модуль. Один шаг его работы описывается матрицей

```text
A = (2 1)
    (3 1)
```

После n шагов результат описывается матрицей A^n. Первая степень — сама A, а каждая следующая получается по правилу A^(n+1) = A^n * A. Матрица одного шага A остаётся неизменной.

Для умножения используется правило «строка на столбец»: если

```text
M = (p q)       N = (u v)
    (r s)           (w x)
```

то

```text
MN = (p*u + q*w   p*v + q*x)
     (r*u + s*w   r*v + s*x)
```

Показатель готовности устройства равен **следу A^n** — сумме верхнего левого и нижнего правого элементов этой матрицы.

Устройство готово к работе, когда показатель **не меньше 5000**.

Рассматриваются целые n **от 1 до 30 включительно**. Гарантируется, что в этом диапазоне устройство достигает готовности.

Найдите:

**а)** Наименьшее n, при котором устройство готово к работе.

**б)** Показатель готовности после этого количества шагов.

**Что сдаётся:** два целых числа через пробел: сначала n, затем след A^n для найденного n.

## Простое объяснение

Представь тот же прибор с индикатором готовности, но после замены модуля один шаг изменяет данные по другому правилу. Нужно снова найти первый шаг, на котором индикатор достигает нужной отметки.

Например, после первого шага след новой матрицы равен 3, после второго — 11. Оба значения ещё меньше 5000. Коэффициенты при умножении берутся из новой матрицы A; все её четыре клетки указаны в условии.

Решение напиши в соседнем `answer.py`. Свои предыдущие решения можно использовать как основу; готового решения этой модификации здесь нет.

**Как это будет на платформе**

В этой учебной имитации матрица, порог и диапазон степеней даны в условии; скачивать ничего не нужно. В поле ответа вводятся два целых числа в указанном порядке. Дома сохрани программу в `answer.py` и сообщи её результат в чате. Промежуточные `print()` можно оставить: в поле переносятся только два итоговых числа. Это формат данного учебного варианта.
