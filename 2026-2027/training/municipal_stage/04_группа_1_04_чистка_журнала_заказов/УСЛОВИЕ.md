## Условие задачи

**Источник:** муниципальный этап ВсОШ по ИИ 2025/26, вариант I, 9–11 классы, задание 4. Файл [МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf](<../../../../2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/МЭ25_ИИ_9-11_Группа_1_Текстовый_разбор.pdf>): полное условие на с. 3, разбор на с. 3–4. Название и текст ниже относятся к исходной задаче; маленькая таблица для практики составлена отдельно.

Дан файл с журналом заказов маркетплейса, который вы можете скачать в форматах XLSX, ODS или CSV. Каждая строка файла содержит три поля в порядке *delivery_hours* (вещественное число), *label* (строка) и *rating* (вещественное число).

Сначала оставьте только строки, где время доставки попадает в диапазон: $1 \leqslant \text{delivery\_hours} \leqslant 96$. Затем в столбце *label* замените все пустые значения модой — самым частым значением этого столбца после фильтрации.

Далее нормируйте *rating*: пусть среди оставшихся строк $\mathrm{rating}_{\min}$ — минимальный рейтинг, а $\mathrm{rating}_{\max}$ — максимальный. Для любой строки её нормированный рейтинг вычисляется по формуле

$$
\frac{\mathrm{rating} - \mathrm{rating}_{\min}}{\mathrm{rating}_{\max} - \mathrm{rating}_{\min}}.
$$

Сколько строк после всех преобразований одновременно удовлетворяют следующим условиям:

- *label* равен моде;
- нормированный рейтинг не меньше $0.8$;
- $\text{delivery\_hours} \leqslant 48$?

**Что сдаётся:** одно целое число — количество строк.

**Учебные данные:** [orders_train.csv](orders_train.csv) — придуманный набор из 12 заказов с теми же тремя полями и теми же правилами обработки. Это не исходные данные олимпиады. Разделитель — запятая, десятичный знак — точка, кодировка — UTF-8; первая строка содержит названия столбцов. Пустая метка записана двумя соседними запятыми. В этом наборе после фильтрации есть непустые метки, мода единственная, минимальный и максимальный рейтинги различаются.

Ученик также добавил [orders6_raw.csv](orders6_raw.csv) из 5000 заказов и написал для него [answer.py](answer.py). Проверенный результат — **711**, он совпадает с ответом в исходном разборе. В PDF есть [ссылка на исходный ODS](https://lab.sirius.online/smt-portal/files/cf3dc1fe32cbe3735168fa63941c4351e4c7b8d9.ods).

## Простое объяснение

Представь журнал интернет-магазина: одна строка — один заказ. `delivery_hours` сообщает, сколько часов его доставляли, `label` — его метку, а `rating` — оценку. В учебном файле метки называются «обычный» и «срочный».

1. Сначала убираем заказы с доставкой меньше 1 или больше 96 часов. Они больше не участвуют ни в каких вычислениях.
2. Среди оставшихся заказов находим самую частую непустую метку. Это **мода**. Вставляем её вместо каждой пустой метки.
3. Пересчитываем оценки на шкалу от 0 до 1: самая маленькая становится 0, самая большая — 1. В учебном файле это 1 и 5, поэтому оценка 4.2 превращается в $\frac{4.2 - 1}{5 - 1} = 0.8$.
4. Считаем заказы, у которых одновременно нужная метка, пересчитанная оценка не ниже 0.8 и доставка не дольше 48 часов.

Границы для пересчёта рейтингов ищем среди **всех строк, оставшихся после первого шага**. Ограничение 48 часов используем только при окончательном подсчёте.

Готовый пример — [example.py](example.py). Используется обычный Python 3 со стандартной библиотекой. CSV ищется рядом с программой, поэтому запуск из корня проекта и из папки задачи даёт один результат. Код разбит на четыре шага и печатает промежуточные значения. Округление применяется только для показа, при сравнении используется исходный результат вычисления.

Для сверки после запуска: остаётся 10 строк; непустых меток «обычный» — 5, «срочный» — 3; заполняются 2 пустые метки; рейтинги от 1 до 5; итог — **3** заказа. Это ответ только к учебному файлу.

### Тот же пример на pandas и NumPy

По просьбе ученика подготовлен [example_pandas.py](example_pandas.py) для знакомства с библиотеками на уже разобранной задаче. Он читает тот же учебный `orders_train.csv`. Вместо перебора строк в циклах обрабатывает столбцы таблицы: фильтрует заказы, заполняет метки, вычисляет нормированные рейтинги и считает подходящие строки.

`df` — вся таблица, а `df["rating"]` — её столбец рейтингов. Сравнение столбца с числом даёт столбец `True`/`False`. Запись `df[условие]` оставляет строки с `True`; несколько условий для столбцов соединяются знаком `&`, каждое сравнение берётся в скобки.

`np.nan` используется как обозначение пропуска. При чтении CSV pandas обычно уже распознаёт пустые ячейки; строка с `replace` из авторского подхода дополнительно учитывает пустые строки. `mode()` находит самые частые непустые значения, `iloc[0]` берёт первое, `fillna()` заполняет пропуски. В наших двух файлах мода единственная, минимальный и максимальный рейтинги различаются.

Пример сохраняет промежуточные `print()` и ограничивает показ таблицы несколькими строками. Проверенные ответы: **3** на `orders_train.csv`; **711** после замены имени входного файла на `orders6_raw.csv`. Это тот же способ решения и тот же порядок обработки, а не новая задача.

Зависимости домашнего примера — pandas и NumPy. На другом компьютере, где их ещё нет, команда установки в выбранный Python:

```powershell

```

Описание операций: [чтение CSV](https://pandas.pydata.org/docs/reference/api/pandas.read_csv.html), [выбор строк](https://pandas.pydata.org/docs/getting_started/intro_tutorials/03_subset_data.html), [мода](https://pandas.pydata.org/docs/reference/api/pandas.Series.mode.html), [заполнение пропусков](https://pandas.pydata.org/docs/reference/api/pandas.Series.fillna.html).

### Как это будет на платформе

В исходной задаче 2025/26 участник скачивает таблицу в одном из трёх предложенных форматов, обрабатывает её и вводит одно целое число. Программа и CSV вместо числа не загружаются.

Чтобы применить учебный код к исходному CSV, нужно указать его имя вместо `orders_train.csv`, проверить заголовок, разделитель и кодировку. На нашем наборе мода единственная и рейтинги различаются; эти свойства нужно проверить и при переходе к другому файлу. Промежуточные `print()` можно оставить для проверки: в поле ответа переносится только итоговое число.

Это формат архивной задачи. Правила школьного этапа и прошлогодние правила отправок автоматически не определяют регламент муниципального этапа 2026/27.
