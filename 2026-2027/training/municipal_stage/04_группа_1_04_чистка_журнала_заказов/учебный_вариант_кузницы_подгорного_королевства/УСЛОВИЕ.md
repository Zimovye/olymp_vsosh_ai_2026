# Кузницы Подгорного королевства

## Условие задачи

**Учебная модификация для самостоятельного решения.** Сюжет, данные и требование о длительности сеансов составлены Codex. Это продолжение знакомого способа работы с таблицей, а не официальное задание.

Гномьи кузницы изготавливают мечи, щиты и латы. Зачарованные наковальни сохраняют отметки о работе. Несколько последовательных отметок могут относиться к одному сеансу изготовления изделий одного вида.

Файл [forges.csv](forges.csv) содержит 48 записей и следующие столбцы:

| Столбец | Значение |
|---|---|
| forge_id | Номер кузницы, целое число. |
| timestamp | Дата и время отметки в формате ГГГГ-ММ-ДДTчч:мм:сс. |
| craft | Вид изделий: «меч», «щит» или «латы». |
| rune_hours | Сколько часов прошло после обновления защитной руны, вещественное число. |
| label | Режим работы горна: «ровно», «скачки» или «перегрев». Иногда отсутствует. |
| rating | Сила отклика зачарованной наковальни, вещественное число. |

Кодировка CSV — UTF-8, разделитель — запятая, десятичный знак — точка. Первая строка содержит названия столбцов. Пропуски встречаются только в *label* и записаны пустыми полями. Даты и время корректны, все часы работают в одном часовом поясе. Секунды во всех отметках равны нулю. Строки перемешаны; для одной пары «кузница, вид изделий» одинаковые моменты времени не повторяются.

**Подготовка данных.**

1. Оставьте только записи с $1 \leqslant \text{rune\_hours} \leqslant 96$.
2. По всей оставшейся таблице найдите моду непустых значений *label* и заполните ею пропуски. Мода единственная; отдельно по кузницам или видам изделий её искать не нужно.
3. Среди всех записей, оставшихся после первого шага, найдите $\mathrm{rating}_{\min}$ и $\mathrm{rating}_{\max}$. Они различаются. Нормированная сила отклика равна

$$
\frac{\mathrm{rating} - \mathrm{rating}_{\min}}{\mathrm{rating}_{\max} - \mathrm{rating}_{\min}}.
$$

4. Оставьте записи, одновременно удовлетворяющие трём условиям:
   - *label* равен найденной моде;
   - нормированная сила отклика не меньше $0.8$;
   - $\text{rune\_hours} \leqslant 48$.

Рейтинги не округляйте. После последнего отбора моду и границы нормализации не пересчитывайте.

**Сеансы работы.**

Сеансы определяются по подготовленной таблице отдельно для каждой пары «номер кузницы, вид изделий». Рассматривайте отметки этой пары в порядке возрастания полной даты и времени.

- Первая оставшаяся отметка начинает сеанс.
- Следующая отметка начинает новый сеанс, если после предыдущей оставшейся отметки той же пары прошло **строго больше 10 минут**. Иначе она продолжает тот же сеанс.
- Ровно 10 минут — ещё тот же сеанс. Сравниваются соседние отметки, а не время начала сеанса.
- Удалённые записи не участвуют в определении сеансов. Время может перейти через полночь, а соседние отметки могут относиться к разным дням.

**Новое требование — длительность.**

Длительность сеанса — время от его первой до его последней оставшейся отметки. Сеанс с одной отметкой учитывается как один сеанс длительностью **0 минут**. Не прибавляйте к длительности ещё 10 минут после последней отметки. Промежуток между разными сеансами в рабочее время не входит.

Суммарное рабочее время кузницы — сумма длительностей всех её сеансов по всем видам изделий. Если сеансы разных видов изделий пересекаются по времени, их длительности всё равно складываются. Все длительности выражайте в целых минутах.

**Формат результата.**

Выведите по одной строке для каждой кузницы, встречавшейся в исходном CSV, в порядке возрастания номера. Каждая строка содержит **шесть целых чисел через пробел**:

1. номер кузницы;
2. количество сеансов изготовления мечей;
3. количество сеансов изготовления щитов;
4. количество сеансов изготовления лат;
5. общее количество сеансов;
6. суммарное рабочее время кузницы в минутах.

Отсутствующим видам изделий соответствуют нулевые количества. Кузницу без подходящих отметок тоже нужно вывести — с пятью нулями после номера. Заголовки и номера строк не печатайте.

Последней строкой выведите **два целых числа**: номер кузницы с наибольшим суммарным рабочим временем и это время в минутах. При равенстве времени выберите кузницу с наименьшим номером. Количество сеансов не является критерием выбора победителя. В файле после подготовки остаётся хотя бы один сеанс ненулевой длительности.

## Простое объяснение

Сначала выполняется знакомая подготовка: фильтрация, заполнение меток модой, нормализация и отбор подходящих отметок. Затем для каждой пары «кузница, вид изделий» определяются сеансы по тому же правилу промежутков, которое использовалось для визитов.

Теперь важно не только сколько раз работали мастера, но и сколько длилась их работа. Например, отметки изготовления щитов в 12:00, 12:08 и 12:16 образуют один сеанс длительностью 16 минут. Одиночная отметка даёт один сеанс и 0 минут. Поэтому кузница с большим количеством сеансов не обязательно работала дольше остальных.

### Как это будет на платформе

В этой учебной задаче ты получаешь CSV и своей программой формируешь отчёт: по шесть чисел для каждой кузницы, затем два числа для победителя. Для проверки формата в итоговом выводе оставь только эти строки; в процессе решения промежуточные `print()` разрешены и полезны.

В исходной муниципальной задаче 2025/26 вводилось одно число, в указанной школьной задаче 2026/27 — три отдельных ответа. Наш отчёт и расчёт длительности — домашняя модификация. Формат будущей официальной задачи определяется её собственным бланком.
