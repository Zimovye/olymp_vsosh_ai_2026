# Учебный вариант по группе II, № 2. Комплекты для экспедиции

## Условие задачи

**Авторская учебная модификация для самостоятельного решения.** Основа: муниципальный этап ВсОШ по искусственному интеллекту 2025/26, группа II, № 2 «Сколько расстановок дают положительный определитель», файл `МЭ25_ИИ_9-11_Группа2_Текстовый_разбор.pdf`, страница 1. [Полное исходное условие](../УСЛОВИЕ.md). Продолжаем ту же тему; изменены доступные данные и объект подсчёта.

Экспедиция испытывает голосовой помощник. На складе есть шесть различных усилителей с коэффициентами **1, 2, 3, 4, 6, 7**, по одному каждого вида. В дорогу нужно взять **ровно четыре** усилителя; два остальных останутся на складе.

На стенде голосового помощника есть два различных канала: **«Эхо»** и **«Фон»**. В каждом канале два гнезда: первое и второе. Перед проверкой выбранные четыре усилителя распределяют по этим четырём гнёздам, используя каждый ровно один раз.

Оба канала получают сигнал уровня **1**. Сигнал последовательно проходит через два установленных усилителя, каждый из которых умножает текущий уровень на свой коэффициент. Поэтому выходной уровень канала равен произведению коэффициентов его двух усилителей.

Настройка стенда рабочая, если **выход «Эха» минус выход «Фона» не меньше 10 и строго меньше 18**.

**Комплект подходит для экспедиции, если выбранные четыре усилителя можно хотя бы одним способом установить в стенд так, чтобы получить рабочую настройку.**

Два комплекта различаются только составом выбранных усилителей. Порядок их перечисления и расположение на стенде не создают нового комплекта. Если один комплект допускает несколько рабочих настроек, он всё равно учитывается **один раз**. Порядок двух усилителей, оставшихся на складе, тоже не учитывается.

**Сколько различных комплектов подходит для экспедиции?**

**Что сдаётся:** одно целое число — количество подходящих комплектов.

## Простое объяснение

Представь коробку, в которую положили четыре усилителя из шести. Её содержимое — один комплект. Можно много раз переставлять эти усилители на стенде, но содержимое коробки от этого не меняется.

Нужно узнать, сколько разных коробок можно собрать так, чтобы для каждой нашлось хотя бы одно рабочее подключение. Например, перечисления «1, 2, 3, 4» и «4, 3, 2, 1» обозначают один и тот же комплект; подходит ли он, ещё нужно проверить по правилу стенда.

Решение напиши в соседнем `answer.py`. Предыдущие решения можно использовать как образец; готовое решение этого варианта не приводится.

**Как это будет на платформе**

В этом учебном варианте все данные даны в условии, скачиваемого файла нет. В учебное поле ответа вводилось бы одно целое число — количество подходящих комплектов. Дома сохрани код в `answer.py` и сообщи полученное число в чате. Промежуточные `print()` можно оставить: в поле ответа переносится только итоговое число. Это форма сдачи учебного варианта по архивной задаче; правила настоящего тура 2026/27 проверяются отдельно.
