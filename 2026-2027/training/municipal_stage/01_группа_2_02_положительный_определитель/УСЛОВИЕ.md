# Группа 2, № 2. Сколько расстановок дают положительный определитель

## Условие задачи

Источник: муниципальный этап ВсОШ по искусственному интеллекту 2025/26, вариант II, 9–11 классы; `МЭ25_ИИ_9-11_Группа2_Текстовый_разбор.pdf`, задание 2, страница 1. Файл находится в `2025-2026/01_Школьный и муниципальный этап/Муниципальный этап/`. [Официальная страница разборов](https://siriusolymp.ru/2025/municipal/ai).

Ниже полное исходное условие; формула записана обычными символами.

Матрицей n × m будем называть таблицу из чисел, состоящую из n строк и m столбцов. Определитель матрицы 2 × 2 — это число, вычисляемое по формуле. Для

```text
p q
r s
```

его значение равно p * s − q * r.

Сколько существует способов расставить числа 1, 2, 3, 6 по клеткам матрицы 2 × 2 (каждое число используется ровно один раз) так, чтобы p * s − q * r > 0?

**Что сдаётся:** одно целое число — количество подходящих расстановок.

## Простое объяснение

Представь четыре карточки с числами 1, 2, 3, 6. Их нужно разложить на столе в два ряда по две карточки. Это и есть матрица 2 × 2. Буквы p, q, r, s обозначают места карточек: p и q сверху, r и s снизу.

Для каждой расстановки умножаем верхнее левое число на нижнее правое, затем вычитаем произведение двух остальных. Получившееся число называется определителем. Считаем расстановку подходящей только тогда, когда результат строго больше нуля.

Например:

```text
1 2       1 * 6 - 2 * 3 = 0 — не подходит.
3 6

2 1       2 * 6 - 1 * 3 = 9 — подходит.
3 6
```

Нужна не одна удачная расстановка, а количество всех удачных. Каждое число используется ровно один раз. Даже если два расположения дают одинаковый определитель, это разные расстановки.

**Готовый учебный разбор:** `example.py` решает исходную задачу на её числах, без изменения условия. Как в знакомой задаче с кодами сейфов, `permutations` перечисляет все 24 порядка четырёх разных чисел. Каждый порядок читаем по строкам: сначала p, q, затем r, s. Вместо совпадений кодов проверяем `det > 0`; переменная `good` считает подходящие расстановки. Программа печатает оба произведения и определитель, чтобы было видно вычисление. Запуск: открыть `example.py` и выполнить целиком; вводить или скачивать данные для этой задачи не нужно.

**Как это будет на платформе**

В исходной задаче 2025/26 участник получает текст условия с четырьмя числами и формулой; скачиваемого файла данных нет. В поле ответа вводится одно целое число — количество подходящих расстановок. Учебный код помогает вычислить его, но код и его промежуточные сообщения в эту задачу не отправляются. Для такого формата сдачи убирать учебные `print()` не требуется: в поле переносится только итоговое число.
