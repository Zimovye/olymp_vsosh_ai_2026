# Задача № 1 IV группы: сколько страниц помещается в контекст чат-бота

## Условие задачи

Источник: школьный этап ВсОШ по искусственному интеллекту 2025/26, IV группа регионов, 9–11 классы, задание 1 — `Разбор_школьного_этапа_ВсОШ_по_ИИ_14.pdf`, страница 1.

Чат-бот — программа, которая читает текст и пишет ответы, — за один раз может обработать не более 128000 условных единиц текста. Примем, что одно слово — это одна условная единица.

В уже начатой беседе хранится история объёмом 500 слов. Вы хотите загрузить документ, на каждой странице которого ровно по 400 слов. Ответ системы должен быть равен по длине исходному тексту; промежуточные рассуждения составляют 15% от длины исходного текста.

Документ какого максимального объёма можно обработать так, чтобы общая сумма

```text
история + исходный текст + рассуждения + ответ
```

не превысила 128000 условных единиц? Ответ выразите в страницах.

**Что сдаётся:** одно целое число — максимальное количество страниц.

## Простое объяснение

Одна страница расходует место не только на 400 слов исходного документа. Для неё нужно учесть ещё такой же по длине ответ и рассуждения объёмом 15% от исходного текста. История беседы занимает отдельные 500 единиц и не зависит от количества страниц.

Сначала запустите `example.py`. В нём лимит равен 1000 единицам, история занимает 100, на странице 100 слов, а рассуждения составляют 20%. Программа отдельно показывает свободное место, расход на одну страницу и максимальное целое количество страниц.

Необязательный видеоразбор официальной задачи: `группа 4, 9–11 классы.mp4`, фрагмент **00:00:17–00:03:03**. В показанном промежуточном вычислении около **00:02:30** есть арифметическая ошибка; для чисел нужно использовать условие и письменный PDF-разбор.

## Как это будет на платформе

Участник получает все числа в условии и вводит одно целое число. Вычисляющий код можно использовать дома, но файл `.py` в этой задаче не загружается. Поскольку спрашивается максимальное полное число страниц, дробную часть результата нужно отбросить, а не округлять до ближайшего.
