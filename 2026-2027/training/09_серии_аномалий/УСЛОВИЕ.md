# Учебная гипотеза: непрерывные серии аномалий

## Условие задачи

Это **полностью придуманная учебная задача**, которая теоретически подходит формату табличной задачи школьного этапа, но **не является опубликованным заданием или прогнозом комплекта 2026/27**.

Работа с последовательными значениями находится в рамках этапа: в официальной демоверсии 2025/26 для 9–11 классов встречалась задача № 6 со скользящим средним (`тестовый 9-11 класс.pdf`). Условие ниже использует другой сюжет и другой способ решения.

Система наблюдает за оборудованием каждую минуту. В файле `data.csv` строки уже расположены по времени. В каждой строке записаны:

- `minute` — номер минуты;
- `anomaly` — результат проверки: `1`, если в эту минуту обнаружена аномалия, и `0`, если всё нормально.

**Инцидентом** называется непрерывная серия соседних строк со значением `anomaly = 1`. Серия заканчивается перед первой следующей строкой с `anomaly = 0` либо в конце файла.

Нужно посчитать количество инцидентов, которые продолжались **не менее двух минут подряд**. Одиночная строка с `anomaly = 1` инцидентом для ответа не считается.

**Что сдаётся:** одно целое число.

Файл `data.csv` содержит 20 проверенных учебных строк. Это не официальные данные олимпиады.

## Простое объяснение

Последовательность `0, 1, 1, 0, 1` содержит две серии единиц: первая имеет длину 2, вторая — длину 1. В ответ засчитывается только первая серия.

Важно не посчитать каждую единицу отдельно. Также нужно учесть серию, которая продолжается до последней строки файла: после неё уже не будет нуля, который обычно сообщает об окончании серии.

Создайте собственный файл `.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

Если бы задача имела такой формат, участник скачал бы таблицу, вычислил количество подходящих серий и ввёл в поле ответа одно число. Код и CSV вместо ответа загружать не нужно. Реальные номер и содержание задания школьного этапа 2026/27 заранее не известны.
