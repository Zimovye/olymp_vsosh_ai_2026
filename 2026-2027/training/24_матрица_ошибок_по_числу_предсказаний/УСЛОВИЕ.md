# Учебная задача № 5: проверка заявок

## Условие задачи

Это **полностью придуманная учебная задача**, основанная на реальной задаче № 5 III группы школьного этапа ВсОШ по искусственному интеллекту 2025/26 для 9–11 классов: `Разбор_школьного_этапа_ВсОШ_по_ИИ_13.pdf`, страницы 5–6. В официальной задаче требовалось найти диапазон `Precision`; здесь добавлено новое условие о количестве положительных предсказаний, а данные и требуемый ответ изменены.

Автоматическая система проверила `N = 120` заявок. Из них `P = 50` действительно соответствуют требованиям, а остальные 70 не соответствуют.

- `TP` — подходящие заявки, которые система верно приняла;
- `FP` — неподходящие заявки, которые система ошибочно приняла;
- `FN` — подходящие заявки, которые система ошибочно отклонила;
- `TN` — неподходящие заявки, которые система верно отклонила.

Известно, что:

```text
Accuracy = (TP + TN) / N = 0,75
```

Всего система пометила как подходящие ровно 60 заявок, то есть:

```text
TP + FP = 60
```

Найдите:

1. `TP`;
2. `FP`;
3. `FN`;
4. `TN`;
5. `Precision = TP / (TP + FP)` в виде несократимой дроби.

Все количества заявок должны быть неотрицательными целыми числами.

**Что сдаётся:** четыре целых числа `TP`, `FP`, `FN`, `TN` в этом порядке и одна несократимая дробь `Precision`.

## Простое объяснение

`Accuracy = 0,75` позволяет узнать, сколько всего ответов системы правильные и сколько ошибочные. Также известно, сколько заявок система приняла: это сумма `TP + FP`.

Нужно подобрать или вычислить четыре количества так, чтобы одновременно выполнялись все связи:

```text
TP + FN = 50
FP + TN = 70
TP + TN = число верных ответов
FP + FN = число ошибок
TP + FP = 60
```

После восстановления единственной подходящей четвёрки вычислите `Precision` и сократите дробь.

Создайте собственный `answer.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В задаче с вводом ответа программа может использоваться для вычислений и проверки, но файл `.py` загружать не нужно. В поля ответа переносятся только четыре количества и дробь в требуемом порядке.
