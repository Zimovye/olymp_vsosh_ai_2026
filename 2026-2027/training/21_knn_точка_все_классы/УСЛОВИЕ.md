# Точка, меняющая класс при изменении `k`

## Условие задачи

Источник: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, III группа регионов, 9–11 классы, задание 3: `Разбор_школьного_этапа_ВсОШ_по_ИИ_13.pdf`, страницы 2–4.

На координатной плоскости даны 18 обучающих точек четырёх классов:

```text
Класс 0: (8, 2), (8, 3), (9, 2)
Класс 1: (3, 4), (4, 3), (5, 3), (2, 3)
Класс 2: (7, 0), (8, -1), (7, -1), (6, 0), (5, 0)
Класс 3: (1, 2), (6, 1), (4, 2), (2, 0), (2, 1), (4, 1)
```

Для новой точки `q` метод `k` ближайших соседей работает так:

1. Берёт `k` ближайших к `q` обучающих точек.
2. Выбирает класс, который встречается среди них чаще всего.
3. При равенстве числа голосов выбирает класс с меньшей суммой обычных расстояний от `q` до выбранных точек этого класса.
4. Если равны и суммы расстояний, выбирает класс с меньшим номером.

При одинаковом расстоянии до нескольких обучающих точек раньше учитывается точка с меньшим номером класса.

Нужно рассмотреть все целочисленные точки `q` внутри наименьшего прямоугольника, содержащего обучающие точки и имеющего стороны, параллельные осям. Для этих данных:

```text
1 ≤ x ≤ 9
-1 ≤ y ≤ 4
```

Для каждой точки `q` получите предсказания при `k = 1, 2, ..., 18`.

Найдите координаты единственной точки `q`, для которой среди этих восемнадцати предсказаний хотя бы один раз встречается каждый класс: 0, 1, 2 и 3.

В отличие от предыдущей задачи группы I, здесь никакие обучающие точки не удаляются: при проверке каждой координаты используются все 18 точек.

**Что сдаётся:** одна пара целых координат `(x, y)`. В разборе 2025/26 точное совпадение ответа оценивалось в 12 баллов.

## Простое объяснение

Мы ищем место на карте, для которого ответ kNN меняется особенно сильно. При маленьком `k` решают самые близкие соседи, а при большом `k` начинают влиять дальние и более многочисленные классы.

Для одной кандидатной точки нужно последовательно получить 18 ответов. Если среди них встретились все четыре номера классов, точка подходит. Затем такой же проверкой перебираются остальные целочисленные координаты прямоугольника.

## Маленький готовый пример

Это **учебный изменённый вариант**, а не дополнительное официальное задание.

В `example.py` используются четыре точки двух классов на одной горизонтальной линии. Программа перебирает целочисленные координаты `x` от 0 до 3, получает последовательность ответов при `k = 1, 2, 3, 4` и оставляет точки, для которых встретились оба класса.

Запусти пример и проследи точку `(1, 0)`: при малых `k` она получает класс 0, а после добавления следующих соседей — класс 1.

Необязательный видеоразбор исходной задачи: `группа 3, 9–11 классы.mp4`, полный фрагмент **00:06:12–00:12:07**, эвристика поиска — **00:09:30–00:12:07**. В видео нет полной проверки всех координат; полный программный перебор приведён в PDF на страницах 3–4.

## Как это будет на платформе

В исходной задаче участник получает рисунок с обучающими точками и правила kNN. Можно написать программу для перебора координат, но в систему отправляется только найденная пара чисел, а не файл `.py`.

Учебный `example.py` печатает последовательности классов для наблюдения. В похожей задаче на платформе нужно оставить вычисления локально и ввести координаты в точном формате условия; содержание комплекта 2026/27 заранее неизвестно.
