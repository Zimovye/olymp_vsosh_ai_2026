# Самостоятельная задача: прогноз по порогу 0,65

## Условие задачи

Это **учебная задача**, составленная по мотивам реального школьного этапа ВсОШ по искусственному интеллекту 2025/26: IV группа регионов, 9–11 классы, задание 6 (`Разбор_школьного_этапа_ВсОШ_по_ИИ_14.pdf`, страницы 3–4).

В файле `data.csv` каждая строка содержит:

- вероятность положительного исхода `p` — число от 0 до 1;
- правильную метку `y`: `1` означает положительный исход, `0` — отрицательный.

Используйте правило предсказания:

- если `p >= 0.65`, предсказание равно `1`;
- если `p < 0.65`, предсказание равно `0`.

Найдите количество строк, для которых предсказание совпадает с правильной меткой `y`.

**Что сдаётся:** одно целое число.

## Простое объяснение

Для каждой строки нужно получить предсказание по числу `p`, сравнить его с правильным ответом `y` и посчитать совпадения.

Значение `p = 0.65` относится к предсказанию `1`, потому что равенство включено в условие.

Создайте свой файл решения в этой папке. Можно смотреть в предыдущий готовый пример, но готового решения для этой задачи здесь нет.

## Как это будет на платформе

В похожей задаче участник скачивает электронную таблицу, вычисляет результат и вводит в поле ответа одно число. Программа используется только для вычисления: загружать `.py` или CSV вместо числового ответа не нужно.
