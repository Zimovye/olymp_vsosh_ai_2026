# Самостоятельная задача: медиана при чётном числе строк

## Условие задачи

Это **учебная аналогичная задача** по типу реального школьного этапа ВсОШ по искусственному интеллекту 2025/26: I группа регионов, 9–11 классы, задание 6 (`Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страницы 5–6).

В каждой строке файла `data.csv` записаны:

- `x1` — число клёнов;
- `x2` — число лип;
- `y` — мнение ботаников: `1`, если участок подходит для эксперимента, и `0`, если не подходит.

Для каждого участка вычисляется оценка:

```text
s = 0.4 * x1 + 0.6 * x2
```

Затем определяется медиана всех оценок `s`.

Участок разрешено использовать, если одновременно выполнены условия:

- `y == 1`;
- `s >= медиана`.

Найдите количество разрешённых участков.

**Что сдаётся:** одно целое число.

Оригинального файла данных в нашем архиве нет. `data.csv` содержит 10 учебных строк.

## Простое объяснение

После вычисления всех десяти оценок расположите их по возрастанию. При чётном количестве значений одного центрального элемента нет: медиана равна среднему арифметическому пятой и шестой оценок.

Медиана считается по всем строкам, включая строки с `y = 0`. После этого нужно посчитать участки, у которых одновременно `y == 1` и оценка не меньше медианы.

Создайте собственный файл `.py` в этой папке. Можно опираться на способ из предыдущей задачи, но готового решения и ответа здесь нет.

## Как это будет на платформе

В исходной официальной задаче участник скачивал таблицу в формате XLSX, ODS или CSV, вычислял оценки и их медиану, затем вводил в поле ответа одно число. Код и таблицу вместо числового ответа не загружали.
