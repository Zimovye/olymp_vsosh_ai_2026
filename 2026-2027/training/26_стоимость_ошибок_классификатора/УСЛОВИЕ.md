# Учебная задача № 5: стоимость ошибок почтового фильтра

## Условие задачи

Это **полностью придуманная учебная задача**, основанная на реальной задаче № 5 I группы школьного этапа ВсОШ по искусственному интеллекту 2025/26 для 9–11 классов: `Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страница 5. В официальной задаче требовалось восстановить число писем со спамом и диапазон `TP`; здесь данные изменены и добавлена стоимость ошибок.

Почтовый фильтр проверил `N = 300` писем. Общее число писем со спамом заранее неизвестно.

- `TP` — письма со спамом, верно помеченные как спам;
- `FP` — обычные письма, ошибочно помеченные как спам;
- `FN` — письма со спамом, ошибочно помеченные как обычные;
- `TN` — обычные письма, верно помеченные как обычные.

Метрики фильтра равны:

```text
Accuracy = (TP + TN) / N = 0,8
Precision = TP / (TP + FP) = 0,5
```

Каждая ошибка имеет стоимость:

```text
ложное срабатывание FP: 2 штрафных балла;
пропущенный спам FN:     5 штрафных баллов.
```

Общая стоимость ошибок:

```text
C = 2 · FP + 5 · FN
```

Найдите:

1. минимально возможное значение `C` и соответствующее ему `TP`;
2. максимально возможное значение `C` и соответствующее ему `TP`.

Все четыре количества должны быть неотрицательными целыми числами. `Precision` должна быть определена, то есть `TP + FP > 0`.

**Что сдаётся:** четыре целых числа в порядке `C_min`, `TP` при минимуме, `C_max`, `TP` при максимуме.

## Простое объяснение

По `Accuracy` можно определить общее количество ошибок `FP + FN`. Значение `Precision = 0,5` задаёт связь между `TP` и `FP`.

Для каждого допустимого `TP` восстановите `FP`, `FN` и `TN`, затем вычислите стоимость `C`. Среди всех допустимых матриц нужно выбрать наименьшую и наибольшую стоимость и запомнить соответствующие значения `TP`.

Создайте собственный `answer.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В задаче с вводом ответа программу можно использовать для перебора и проверки, но файл `.py` загружать не нужно. В поля ответа переносятся только четыре найденных целых числа.
