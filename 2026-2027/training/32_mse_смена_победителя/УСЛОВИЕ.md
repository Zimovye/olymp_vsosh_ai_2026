# Учебная задача № 3: смена лучшей модели

## Условие задачи

Это **учебная модификация**, а не официальное задание и не прогноз комплекта 2026/27.

Источник исходного типа задачи: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, II группа регионов, 9–11 классы, задание 3 — `Разбор_школьного_этапа_ВсОШ_по_ИИ_15.pdf`, страницы 2–3.

Даны две модели:

```text
Модель 1: ŷ = 2x
Модель 2: ŷ = x + 1
```

Начальный набор состоит из двух точек:

```text
(0, 0), (1, 2)
```

После этого к набору по одной добавляются три точки в указанном порядке:

```text
1-я добавленная точка: (2, 4)
2-я добавленная точка: (3, 4)
3-я добавленная точка: (4, 8)
```

Добавленные точки не удаляются. Например, после второго добавления MSE вычисляется уже на четырёх точках: двух начальных, первой добавленной и второй добавленной.

Качество модели оценивается по средней квадратичной ошибке:

```text
MSE = сумма (y − ŷ)² / количество точек
```

Нужно:

1. определить лучшую модель на начальном наборе;
2. определить лучшую модель после каждого из трёх добавлений;
3. найти номер первого добавления, после которого победитель отличается от победителя на предыдущем шаге.

Для обозначения результата используйте:

```text
1 — MSE модели 1 меньше;
2 — MSE модели 2 меньше;
0 — MSE моделей равны.
```

**Что сдаётся:** в первой строке — четыре обозначения через пробел: результат на начальном наборе и результаты после добавлений 1, 2 и 3. Во второй строке — номер первого добавления, после которого обозначение изменилось.

## Простое объяснение

Нельзя оценивать каждую новую точку отдельно. После добавления точки обе модели нужно заново сравнить на всём накопленном наборе.

Удобно начать со списка начальных точек, вычислить первый результат, а затем добавлять по одной точке и сохранять новый результат. В конце нужно сравнить соседние обозначения и найти первое изменение.

Создай `answer.py` в этой папке. Готового решения здесь нет. MSE сравнивай до округления.

## Как это будет на платформе

Это учебная модификация задачи с вводом ответа. Программа нужна только для последовательных вычислений; в условной форме сдачи передаются две строки, а не файл `.py`.

В реальной задаче необходимо соблюдать формат конкретных полей на платформе. Последовательное добавление точек и кодирование ответов числами `0`, `1`, `2` придуманы для этой тренировки.
