# Учебная гипотеза: совместное решение двух классификаторов

## Условие задачи

Это **придуманная учебная задача**, которая теоретически соответствует знакомому формату табличного задания, но **не является опубликованным заданием или прогнозом комплекта 2026/27**.

Основа для варианта — реальные задания № 6 школьного этапа 2025/26 для групп I–IV, 9–11 классы. В них требовалось вычислять вспомогательные значения по строкам таблицы и считать строки по условию. Здесь объединены взвешенная оценка из I группы и пороговое предсказание из IV группы.

В каждой строке файла `data.csv` записаны:

- `p1` — вероятность положительного исхода по мнению первого классификатора;
- `p2` — вероятность положительного исхода по мнению второго классификатора;
- `y` — правильная метка: `1` или `0`.

Общая оценка двух классификаторов вычисляется так:

```text
q = 0.6 * p1 + 0.4 * p2
```

По общей оценке строится предсказание:

- если `q >= 0.6`, предсказание равно `1`;
- если `q < 0.6`, предсказание равно `0`.

Найдите количество строк, в которых предсказание **не совпало** с правильной меткой `y`.

**Что сдаётся:** одно целое число — количество ошибок.

Файл `data.csv` содержит 14 проверенных учебных строк. Это не официальные данные олимпиады.

## Простое объяснение

Первому классификатору доверяют немного больше, поэтому его вероятность умножается на `0.6`, а вероятность второго — на `0.4`. После сложения получается общая оценка `q`.

Важно выполнить все действия по порядку: вычислить `q`, получить предсказание по порогу и сравнить его с `y`. В отличие от предыдущих задач, считать нужно не совпадения, а ошибки. Равенство `q = 0.6` относится к предсказанию `1`.

Создайте собственный файл `.py` в этой папке. Готового решения и ответа здесь нет.
