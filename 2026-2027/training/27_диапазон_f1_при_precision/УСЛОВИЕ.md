# Учебная задача № 5: диапазон F1 при заданном Precision

## Условие задачи

Это **полностью придуманная учебная задача**, основанная на реальной задаче № 5 IV группы школьного этапа ВсОШ по искусственному интеллекту 2025/26 для 9–11 классов: `Разбор_школьного_этапа_ВсОШ_по_ИИ_14.pdf`, страница 3. В официальной задаче требовалось найти границы `Accuracy` при `Precision = 0,5`; здесь изменены данные, значение `Precision` и исследуемая метрика.

Классификатор проверил `N = 200` объектов:

- `140` объектов на самом деле относятся к положительному классу;
- `60` объектов относятся к отрицательному классу.

Для классификатора известно:

```text
Precision = TP / (TP + FP) = 3/5
```

Метрика `F1` вычисляется по формуле:

```text
F1 = 2 · TP / (2 · TP + FP + FN)
```

Все четыре количества `TP`, `FP`, `FN`, `TN` должны быть неотрицательными целыми числами. `Precision` должна быть определена, то есть `TP + FP > 0`.

Найдите:

1. минимально возможное значение `F1` и соответствующее ему `TP`;
2. максимально возможное значение `F1` и соответствующее ему `TP`.

Значения `F1` запишите в виде несократимых дробей.

**Что сдаётся:** четыре значения в порядке `F1_min`, `TP` при минимуме, `F1_max`, `TP` при максимуме.

## Простое объяснение

`Precision = 3/5` означает, что среди каждых пяти положительных предсказаний три верные, а два ошибочные. Поэтому допустимые `TP` и `FP` связаны одним целочисленным соотношением.

Переберите допустимые варианты, восстановите `FN` и `TN`, а затем для каждого варианта вычислите `F1`. Обратите внимание: количество настоящих отрицательных объектов тоже ограничивает возможные значения `FP`.

Создайте собственный `answer.py` в этой папке. Готового решения и ответа здесь нет.
