# Учебная задача № 3: порог итогового балла

## Условие задачи

Это **учебная модификация**, а не официальное задание и не прогноз комплекта 2026/27.

Источник исходного типа задачи: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, IV группа регионов, 9–11 классы, задание 3 — `Разбор_школьного_этапа_ВсОШ_по_ИИ_14.pdf`, страница 2.

У школьника есть 10 домашних заданий и одна контрольная работа. Для каждого домашнего задания он выбирает один из двух вариантов:

- решить самостоятельно;
- списать из готовых домашних заданий.

Пусть `Kₜ` — уровень знаний перед домашним заданием с номером `t`. Вначале `K₁ = 0`.

Если ученик самостоятельно решает задание, его уровень знаний повышается на 1. Если списывает, знания не изменяются.

Оценка за домашнее задание:

```text
если решено самостоятельно: Hₜ = 1,5 + 0,3Kₜ
если списано:               Hₜ = 4,5
```

Оценка за контрольную после всех домашних заданий:

```text
E = min(1 + 0,5K₁₁; 5)
```

Итоговый балл:

```text
S = 0,4 · (H₁ + H₂ + ... + H₁₀) / 10 + 0,6 · E
```

В официальной задаче требовалось максимизировать `S`. Здесь вопрос изменён.

Найдите:

1. все значения `h` от 0 до 10, при которых точное значение `S` не меньше `4,150`;
2. наименьшее подходящее значение `h`.

Здесь `h` — количество самостоятельно выполненных домашних заданий. Сравнивайте с порогом исходное вычисленное значение `S`, а не значение после округления.

**Что сдаётся:** в первой строке — все подходящие значения `h` по возрастанию через пробел; во второй строке — наименьшее из них.

## Простое объяснение

Теперь не нужно искать единственный самый большой итоговый балл. Для каждого количества самостоятельных работ от 0 до 10 нужно вычислить `S` и проверить условие `S ≥ 4,150`.

Важно проверить все значения: после достижения максимальной оценки за контрольную дополнительные самостоятельные работы могут снизить среднюю оценку за домашние задания. Поэтому из того, что некоторое `h` подходит, не следует, что подойдут все большие значения.

Создай `answer.py` в этой папке. Можно взять собственную идею перебора из задачи 22, но программа должна сохранить все подходящие `h`, а не только вариант с максимальным `S`.

## Как это будет на платформе

Это учебная модификация задачи с вводом ответа. Программа нужна только для вычисления; загружать `.py` не требуется. В условной форме сдачи передаются список значений `h` и отдельно его наименьший элемент.

В реальной задаче нужно следовать формату конкретных полей на платформе. Новое требование про порог `4,150` не взято из официального комплекта и не обещает похожей задачи в сезоне 2026/27.
