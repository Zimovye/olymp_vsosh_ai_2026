# Самостоятельная задача: фильтр заявок

## Условие задачи

Это **учебная изменённая задача**, составленная по мотивам реального школьного этапа ВсОШ по искусственному интеллекту 2025/26: I группа регионов, 9–11 классы, задание 5 (`Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страница 5).

Автоматический фильтр проверил `N = 100` заявок. Положительный класс — заявки, которые действительно соответствуют требованиям. Обозначим через `P` общее количество таких заявок.

- `TP` — подходящие заявки, которые фильтр верно принял;
- `FP` — неподходящие заявки, которые фильтр ошибочно принял;
- `FN` — подходящие заявки, которые фильтр ошибочно отклонил;
- `TN` — неподходящие заявки, которые фильтр верно отклонил.

Метрики:

```text
Precision = TP / (TP + FP)
Accuracy = (TP + TN) / N
```

Известно, что `Accuracy = 0,6` и `Precision = 0,75`.

Найдите:

1. минимальное возможное значение `P`;
2. максимальное возможное значение `P`;
3. минимальное возможное значение `TP`;
4. максимальное возможное значение `TP`.

Все количества заявок должны быть неотрицательными целыми числами. Значение `Precision` должно быть определено, то есть `TP + FP > 0`.

**Что сдаётся:** четыре целых числа в указанном порядке.

## Простое объяснение

Сначала по `Accuracy` определите общее количество верных ответов и ошибок. Затем переведите `Precision = 0,75` в точное соотношение между `TP` и `FP`.

Перебирайте только целые допустимые пары `TP` и `FP`. Для каждой пары вычислите `TN`, `FN` и настоящее количество положительных заявок `P = TP + FN`. Не забудьте одновременно проверить `TN >= 0` и `FN >= 0`.

Создайте собственный `answer.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В задании такого формата участник вводит четыре числа в указанные поля. Программу можно использовать для вычислений и проверки, но вместо числового ответа файл `.py` не загружается.
