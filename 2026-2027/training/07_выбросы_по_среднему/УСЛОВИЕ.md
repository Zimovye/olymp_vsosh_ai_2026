# Самостоятельная задача: выбросы в третьем столбце

## Условие задачи

Это **учебная задача** с маленькими данными по типу реального школьного этапа ВсОШ по искусственному интеллекту 2025/26: III группа регионов, 9–11 классы, задание 6 (`Разбор_школьного_этапа_ВсОШ_по_ИИ_13.pdf`, страница 6).

В каждой строке файла `data.csv` записаны пять натуральных чисел. Значение третьего столбца обозначим через `x`.

Сначала найдите среднее арифметическое всех значений `x`:

```text
среднее = сумма всех x / количество строк
```

Значение третьего столбца считается выбросом, если выполняется строгое неравенство:

```text
abs(x - среднее) > среднее
```

Найдите количество строк, в которых значение третьего столбца является выбросом.

**Что сдаётся:** одно целое число.

Оригинального файла данных в нашем архиве нет. `data.csv` содержит 10 проверенных учебных строк.

## Простое объяснение

Среднее показывает обычный уровень значений третьего столбца. Для каждой строки нужно найти расстояние от `x` до среднего — модуль разности `abs(x - среднее)` — и сравнить его со средним.

Знак `>` строгий. Например, если среднее равно `8`, то для `x = 16` отклонение равно `8`, поэтому это ещё не выброс. Для `x = 17` отклонение равно `9`, и такое значение уже считается выбросом.

Создайте собственный файл `.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В официальной задаче участник скачивал таблицу в формате XLSX, ODS или CSV, вычислял среднее третьего столбца и количество выбросов, затем вводил в поле ответа одно число. Код и таблицу вместо числового ответа не загружали.
