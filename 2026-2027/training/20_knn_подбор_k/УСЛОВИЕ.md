# Подбор числа соседей `k` для метода kNN

## Условие задачи

Источник: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, I группа регионов, 9–11 классы, задание 3: `Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страницы 2–3.

На плоскости даны 18 точек с целыми координатами. У каждой точки есть номер класса от 0 до 3:

- класс 0 — красный;
- класс 1 — синий;
- класс 2 — зелёный;
- класс 3 — жёлтый.

В исходном PDF точки показаны на графике. Их координаты и классы:

```text
Класс 0: (8, 2), (8, 3), (9, 2)
Класс 1: (3, 4), (4, 3), (5, 3), (2, 3)
Класс 2: (5, 0), (7, 0), (8, -1), (7, -1), (6, 0)
Класс 3: (1, 2), (6, 1), (4, 2), (2, 0), (2, 1), (4, 1)
```

Метод `k` ближайших соседей определяет класс новой точки так:

1. Находит `k` ближайших к ней точек из обучающего списка.
2. Если несколько точек находятся на одинаковом расстоянии, раньше берётся точка с меньшим номером класса.
3. Выбирает класс, который встречается среди соседей чаще всего.
4. При равенстве числа голосов выбирает класс с меньшей суммой расстояний до новой точки.
5. Если равны и суммы расстояний, выбирает класс с меньшим номером.

Нужно проверить три выделенные точки:

- `(8, 2)` настоящего класса 0;
- `(3, 4)` настоящего класса 1;
- `(5, 0)` настоящего класса 2.

Для честной проверки все три выделенные точки заранее удаляются из обучающего списка. Классификация каждой из них выполняется по оставшимся 15 точкам.

Найдите все значения `k` от 1 до 15, при которых метод правильно определяет класс всех трёх выделенных точек одновременно.

**Что сдаётся:** выбранные значения `k`. В разборе 2025/26 балл вычислялся по формуле `(число правильно выбранных − число неправильно выбранных) · 4`, но не меньше нуля; максимум — 12 баллов.

## Простое объяснение

Представь, что неизвестная точка спрашивает ближайших соседей, к какому классу ей относиться. При `k = 1` отвечает один ближайший сосед, а при `k = 5` голосуют пять соседей.

При изменении `k` результат может меняться: сначала рядом могут оказаться точки правильного класса, а затем в голосование войдут точки другого класса. В этой задаче одно и то же `k` должно подойти сразу для трёх проверяемых точек.

Расстояние между `(x₁, y₁)` и `(x₂, y₂)` вычисляется так:

```text
√((x₁ − x₂)² + (y₁ − y₂)²)
```

## Маленький готовый пример

Это **учебный изменённый вариант**, а не дополнительное официальное задание.

В `example.py` есть одна проверяемая точка класса 0 и пять обучающих точек классов 0 и 1. Программа:

1. вычисляет расстояния;
2. сортирует соседей;
3. перебирает `k` от 1 до 5;
4. считает голоса и суммы расстояний;
5. печатает полученный класс при каждом `k`.

Сначала запусти готовый файл и проследи, почему при `k = 2` возникает ничья по голосам, но побеждает класс 0.

Необязательный видеоразбор исходной задачи: `группа 2, 9–11 классы.mp4`, полный фрагмент **00:09:10–00:18:18**, практическая проверка значений `k` — **00:12:19–00:18:18**.

## Как это будет на платформе

В исходной задаче участник получает график с точками, правила разрешения ничьей и несколько возможных значений `k`. Нужно выбрать значения, которые одновременно подходят всем выделенным точкам; загружать вычисляющую программу не требуется.

Учебный `example.py` печатает много промежуточных значений для понимания. Если похожая задача встретится в сезоне 2026/27, нужно отправить только значения в точном формате, указанном на платформе; новый комплект заранее неизвестен.
