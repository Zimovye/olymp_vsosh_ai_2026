# Учебная гипотеза: резкие изменения сигнала

## Условие задачи

Это **полностью придуманная учебная задача**. Она теоретически подходит формату табличной задачи школьного этапа, но **не является опубликованным заданием или прогнозом комплекта 2026/27**.

Работа с соседними значениями последовательности находится в рамках этапа: в официальной демоверсии 2025/26 для 9–11 классов задача № 6 была посвящена скользящему среднему (`тестовый 9-11 класс.pdf`). В новой задаче используются другой сюжет, другое условие и другой способ подсчёта.

Датчик каждую минуту измеряет уровень сигнала. Строки файла `data.csv` уже расположены по времени. В каждой строке записаны:

- `minute` — номер минуты;
- `signal` — измеренный целый уровень сигнала.

**Резким изменением** называется переход между двумя соседними минутами, при котором модуль разности уровней сигнала не меньше `5`:

```text
|текущее значение − предыдущее значение| >= 5
```

Нужно посчитать количество резких изменений во всём файле. Первую строку не с чем сравнивать, поэтому сама по себе она резким изменением не считается.

**Что сдаётся:** одно целое число.

Файл `data.csv` содержит 18 проверенных учебных строк. Это не официальные данные олимпиады.

## Простое объяснение

Для значений `10, 14, 9, 12` разности соседних значений по модулю равны `4`, `5` и `3`. При границе `5` резким считается только переход от `14` к `9`.

Здесь не нужно искать серии. Для каждой строки, начиная со второй, достаточно сравнить текущее значение только с предыдущим, а затем запомнить текущее значение для следующего сравнения. Равенство границе `5` тоже засчитывается.

Создай собственный файл `answer.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

Если бы задача имела такой формат, участник скачал бы таблицу, программой вычислил количество резких изменений и ввёл в поле ответа одно целое число. Код и CSV вместо ответа загружать не нужно. Реальные номер и содержание задания школьного этапа 2026/27 заранее не известны.
