# Учебная задача № 5: число матриц и количество положительных объектов

## Условие задачи

Это **полностью придуманная учебная задача**, основанная на реальной задаче № 5 I группы школьного этапа ВсОШ по искусственному интеллекту 2025/26 для 9–11 классов: `Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страница 5. В официальной задаче по `Accuracy` и `Precision = 0,5` восстанавливалось число настоящих положительных объектов и диапазон `TP`; здесь изменены данные, значение `Precision` и требуемые результаты.

Классификатор проверил `N = 200` объектов. Число объектов, которые на самом деле относятся к положительному классу, заранее неизвестно.

Известны метрики:

```text
Accuracy = (TP + TN) / N = 0,8
Precision = TP / (TP + FP) = 2/5
```

Все четыре количества `TP`, `FP`, `FN`, `TN` должны быть неотрицательными целыми числами. `Precision` должна быть определена, то есть `TP + FP > 0`.

Две матрицы ошибок считаются различными, если в них отличается хотя бы одно из четырёх значений `TP`, `FP`, `FN`, `TN`.

Для каждого допустимого варианта число настоящих положительных объектов равно:

```text
P = TP + FN
```

Найдите:

1. количество всех допустимых матриц ошибок;
2. минимально возможное `P` и соответствующее ему `TP`;
3. максимально возможное `P` и соответствующее ему `TP`.

**Что сдаётся:** пять целых чисел в порядке: количество матриц, `P_min`, `TP` при минимуме, `P_max`, `TP` при максимуме.

## Простое объяснение

Сначала по `Accuracy` определите общее число правильных ответов и общее число ошибок. Затем используйте `Precision = 2/5`, чтобы получить целочисленную связь между `TP` и `FP`.

Переберите только те значения, при которых все четыре клетки матрицы ошибок остаются целыми и неотрицательными. Каждый допустимый набор нужно учесть один раз, а для крайних значений `P` сохранить соответствующее `TP`.

Создайте собственный `answer.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В задаче с вводом ответа программу можно использовать для перебора и проверки, но файл `.py` загружать не нужно. В поля ответа переносятся пять найденных целых чисел в указанном порядке.

Это учебная модификация, а не прогноз содержания школьного этапа 2026/27.
