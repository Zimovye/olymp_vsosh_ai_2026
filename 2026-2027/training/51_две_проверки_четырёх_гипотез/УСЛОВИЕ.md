# Задача № 4 IV группы: две проверки четырёх гипотез

## Условие задачи

Это официальная задача № 4 IV группы школьного этапа ВсОШ по искусственному интеллекту 2025/26 для 9–11 классов.

Источник: `Разбор_школьного_этапа_ВсОШ_по_ИИ_14.pdf`, страницы 2–3.

Учитель объясняет детям, что если они хотят проверить гипотезу, её нужно пытаться опровергнуть. Он загадал правило, которому удовлетворяет тройка целых чисел `1, 2, 4`. Известно, что это правило — одно из четырёх:

1. числа строго возрастают;
2. все числа положительные;
3. подходят любые три числа;
4. произведение первого и последнего чисел равно квадрату второго.

Выберите две тройки чисел так, чтобы по паре ответов «да/нет» можно было однозначно понять, какое именно из четырёх правил загадано.

**Что сдаётся:** выбор двух троек чисел.

## Простое объяснение

Каждую выбранную тройку учитель проверяет по загаданному правилу и отвечает только «да» или «нет». Две проверки дают пару ответов, например `(да, нет)`.

Нужно добиться, чтобы у каждого из четырёх правил получилась своя пара ответов. Если у двух правил пары совпадут, отличить эти правила не получится.

Сначала запустите `example.py`. Там показана уменьшенная учебная задача с тремя правилами. Код проверяет две тройки и печатает получившуюся пару ответов для каждого правила.

Необязательный видеоразбор официальной задачи: `Видеоразборы/группа 4, 9–11 классы.mp4`, фрагмент **00:16:21–00:19:39**. В нём сразу разбирается официальное решение, поэтому лучше посмотреть его после собственной попытки. Полный фрагмент с показом условия начинается в **00:14:54**.

## Как это будет на платформе

В задаче школьного этапа 2025/26 требовалось выбрать две тройки; программа и файл `.py` не сдавались. Код можно использовать дома, чтобы аккуратно заполнить таблицу ответов, но на платформу переносится только требуемый выбор.

В новом сезоне похожий способ рассуждения может встретиться с другими правилами или другим форматом ответа. Наличие именно такой задачи не гарантируется.
