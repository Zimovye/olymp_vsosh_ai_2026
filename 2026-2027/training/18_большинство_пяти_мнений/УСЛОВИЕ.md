# Учебный аналог: большинство пяти мнений

## Условие задачи

Это **изменённая учебная задача**, похожая на реальную задачу № 6 из группы II школьного этапа 2025/26. Новое условие и файл данных не являются официальным заданием или прогнозом комплекта 2026/27.

**Источник исходного типа задачи:**

- `Разбор_школьного_этапа_ВсОШ_по_ИИ_15.pdf`, группа II, 9–11 классы, задача № 6, страницы 5–6;
- видео `группа 1, 9–11 классы.mp4` (несмотря на имя файла, внутри разобрана группа II), фрагмент **00:32:35–00:36:06**; практическая часть с формулами — **00:33:06–00:36:06**.

В исходной задаче решение принималось большинством трёх мнений. В этом учебном аналоге используются пять моделей.

Для каждого объекта известны:

- `y` — правильная метка объекта;
- `n1`, `n2`, `n3`, `n4`, `n5` — предсказания пяти моделей.

Все значения равны `0` или `1`. Итоговое предсказание ансамбля равно `1`, если за класс `1` проголосовали **не менее трёх моделей**. Иначе итоговое предсказание равно `0`.

Нужно определить, для скольких строк итоговое предсказание ансамбля совпадает с правильной меткой `y`.

**Что сдаётся:** одно целое число.

Файл `data.csv` содержит 20 проверенных учебных строк.

## Простое объяснение

Пять моделей — как пять членов жюри. Если голоса равны `1, 0, 1, 1, 0`, то за единицу подано три голоса, поэтому общее решение равно `1`. После этого его нужно сравнить с `y` в той же строке.

Для решения достаточно просуммировать пять голосов в каждой строке, получить итоговое предсказание и увеличить счётчик при совпадении с `y`.

Создай собственный файл `answer.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В реальной задаче этого типа участник скачивает таблицу, вычисляет число совпадений и вводит в поле ответа одно целое число. Программа используется только для вычисления: загружать `.py` или CSV вместо ответа не нужно. В этом упражнении используются учебные данные, а реальное содержание задачи 2026/27 заранее неизвестно.
