# Классификация по порогу вероятности 0,6

## Условие задачи

Источник: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, IV группа регионов, 9–11 классы, задание 6: `Разбор_школьного_этапа_ВсОШ_по_ИИ_14.pdf`, страницы 3–4.

Данные для выполнения задания находятся в файле электронной таблицы. Его можно скачать в одном из трёх форматов: XLSX, ODS или CSV.

В каждой строке находятся два числа:

- вероятность положительного исхода `p` — число от 0 до 1;
- правильная метка `y`: `1` означает положительный исход, `0` — отрицательный.

Используется правило предсказания:

- если `p >= 0,6`, предсказание равно `1`;
- если `p < 0,6`, предсказание равно `0`.

Найдите количество строк, для которых предсказание совпадает с правильной меткой `y`.

На школьном этапе 2025/26 требовалось отправить одно число. За точное совпадение начислялось 12 баллов.

Оригинального файла с данными в нашем архиве нет. Поэтому `data.csv` в этой папке — маленький **учебный набор**, а не восстановленные официальные данные.

## Простое объяснение

Число `p` показывает, насколько модель уверена в положительном исходе. Например, при `p = 0.75` программа предсказывает `1`. Если правильная метка тоже равна `1`, строка засчитывается как верная.

Важно проверить границу: при `p = 0.60` предсказание уже равно `1`, потому что в условии стоит знак `>=`.

Нужно повторить это действие для каждой строки и посчитать все совпадения.

## Как это будет на платформе

Участник скачивает электронную таблицу, вычисляет количество совпадений и вводит в поле ответа **одно целое число**. Код и CSV загружать не нужно.

В учебном примере программа печатает промежуточные результаты. При работе с официальным файлом нужно будет указать его имя и проверить расположение столбцов и разделитель. В поле ответа переносится только итоговое число из последней строки вывода.
