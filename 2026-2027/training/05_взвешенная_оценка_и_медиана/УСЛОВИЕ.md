# Самостоятельная задача: взвешенная оценка и медиана

## Условие задачи

Это **учебная задача** с маленькими данными по типу реального школьного этапа ВсОШ по искусственному интеллекту 2025/26: I группа регионов, 9–11 классы, задание 6 (`Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страницы 5–6).

Ботаники исследуют участки. В каждой строке файла `data.csv` записаны:

- `x1` — число клёнов;
- `x2` — число лип;
- `y` — мнение ботаников: `1`, если участок подходит для эксперимента, и `0`, если не подходит.

Для каждого участка вычисляется взвешенная оценка:

```text
s = 0.4 * x1 + 0.6 * x2
```

Затем определяется медиана всех полученных оценок `s`.

Участок разрешено использовать, если одновременно выполнены условия:

- `y == 1`;
- `s >= медиана`.

Найдите количество разрешённых участков.

**Что сдаётся:** одно целое число.

Оригинального файла данных в нашем архиве нет. `data.csv` в этой папке — проверенный учебный набор из 11 строк, а не восстановленные официальные данные.

## Простое объяснение

Сначала нужно вычислить оценку `s` для **каждой** строки и сохранить все оценки. Затем расположить 11 оценок по возрастанию. Медиана — число, которое окажется посередине: в наборе из 11 значений это шестое значение.

Медиана считается по всем участкам, включая строки с `y = 0`. Только после нахождения медианы нужно посчитать строки, где одновременно `y == 1` и оценка не меньше медианы.

Создайте собственный файл `.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В исходной официальной задаче участник скачивал таблицу в формате XLSX, ODS или CSV, вычислял оценки и их медиану, затем вводил в поле ответа одно число. Код и таблицу вместо числового ответа не загружали.
