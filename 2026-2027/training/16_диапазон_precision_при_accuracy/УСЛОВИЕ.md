# Диапазон Precision при известной Accuracy

## Условие задачи

Источник: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, III группа регионов, 9–11 классы, задание 5: `Разбор_школьного_этапа_ВсОШ_по_ИИ_13.pdf`, страницы 5–6.

В задаче бинарной классификации дано всего `N = 1000` объектов, из них положительных `P = 400` и отрицательных `N − P = 600`.

- `TP` — верно предсказанные положительные объекты (True Positives);
- `FP` — отрицательные объекты, ошибочно предсказанные как положительные (False Positives);
- `FN` — положительные объекты, ошибочно предсказанные как отрицательные (False Negatives);
- `TN` — верно предсказанные отрицательные объекты (True Negatives).

Метрики:

```text
Precision = TP / (TP + FP)
Accuracy = (TP + TN) / N
```

Известно, что `Accuracy = 0,8`. Найдите диапазон возможных значений `Precision`.

Все четыре количества должны быть неотрицательными целыми числами. Значение `Precision` должно быть определено, то есть `TP + FP > 0`.

**Что сдаётся:** два числа — нижняя и верхняя границы `Precision`. В разборе 2025/26 каждая верная граница оценивалась в 6 баллов, всего можно было получить 12 баллов.

## Простое объяснение

Теперь количество положительных объектов известно, но сама `Precision` заранее не задана. Из `Accuracy` можно получить общее количество правильных ответов и ошибок.

Для каждого возможного `TP` сначала вычисляется `FN = P − TP`. Оставшиеся ошибки — это `FP`. После проверки неотрицательности всех четырёх количеств можно вычислить `Precision` и найти её наименьшее и наибольшее значения.

## Маленький готовый пример

Это **учебный изменённый вариант**, а не дополнительное официальное задание.

Всего есть 20 объектов: 8 положительных и 12 отрицательных. Известно, что `Accuracy = 0,75`. Нужно найти диапазон возможных значений `Precision`.

Файл `example.py` перебирает возможные `TP`, восстанавливает остальные три количества и оставляет только допустимые комбинации.

## Как это будет на платформе

Участник получает условие с готовыми размерами классов и значением `Accuracy`. Вычисления можно выполнить вручную или проверить программой, но загружать код не нужно. В ответ передаются две границы `Precision` в требуемом формате.

В учебном `example.py` оставлены промежуточные `print()`. На платформу переносятся только нижняя и верхняя границы.
