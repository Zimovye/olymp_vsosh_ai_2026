# Учебная задача № 3: удаление одной точки

## Условие задачи

Это **учебная модификация**, а не официальное задание и не прогноз комплекта 2026/27.

Источник исходного типа задачи: реальный школьный этап ВсОШ по искусственному интеллекту 2025/26, II группа регионов, 9–11 классы, задание 3 — `Разбор_школьного_этапа_ВсОШ_по_ИИ_15.pdf`, страницы 2–3.

Даны две модели:

```text
Модель 1: y_pred = 2x
Модель 2: y_pred = x + 1
```

И набор из четырёх пронумерованных точек:

```text
1: (0, 2)
2: (2, 2)
3: (3, 4)
4: (4, 9)
```

Качество модели оценивается по средней квадратичной ошибке:

```text
MSE = сумма (y - y_pred)² / количество точек
```

Меньшее значение MSE означает лучшую модель. Для обозначения результата используй:

```text
1 — MSE модели 1 меньше;
2 — MSE модели 2 меньше;
0 — MSE моделей равны.
```

Сначала определи результат на полном наборе. Затем по очереди проверь четыре случая: удалить только точку 1, удалить только точку 2, удалить только точку 3 и удалить только точку 4. Каждая проверка начинается заново с полного набора: удаления **не накапливаются**.

Найди также номера всех точек, удаление которых меняет результат по сравнению с полным набором.

**Что сдаётся:**

- в первой строке — пять обозначений через пробел: результат на полном наборе, затем результаты после удаления точек 1, 2, 3 и 4;
- во второй строке — номера всех точек, удаление которых изменило результат, по возрастанию через пробел. Если таких точек нет, выведи `-1`.

MSE сравнивай до округления.

## Простое объяснение

Одна необычная точка может сильно повлиять на среднюю ошибку и даже поменять победителя. Здесь нужно временно убрать одну точку, пересчитать ошибки двух моделей на оставшихся трёх точках, а затем вернуть её и проверить следующую.

Удобно написать функцию, которая получает список точек и возвращает строку `"0"`, `"1"` или `"2"`. Сначала вызови её для всего списка, затем четыре раза — для списка без одной выбранной точки.

Напиши решение в `answer.py`. Готового решения в папке нет.

## Как это будет на платформе

Это учебная модификация задачи с вводом ответа. Программа нужна для вычислений дома; в условной форме сдачи вводятся две полученные строки, а файл `.py` не загружается.

В официальной задаче нужно следовать формату конкретных полей на платформе. Удаление точек и обозначения `0`, `1`, `2` придуманы для этой тренировки.
