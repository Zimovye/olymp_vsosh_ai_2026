# Самостоятельная задача: взвешенная оценка участка

## Условие задачи

Это **учебная изменённая задача**, составленная по мотивам реального школьного этапа ВсОШ по искусственному интеллекту 2025/26: I группа регионов, 9–11 классы, задание 6 (`Разбор_школьного_этапа_ВсОШ_по_ИИ_11.pdf`, страницы 5–6).

Ботаники исследуют участки. В каждой строке файла `data.csv` записаны:

- `x1` — число клёнов;
- `x2` — число лип;
- `y` — мнение ботаников: `1`, если участок подходит для эксперимента, и `0`, если не подходит.

Для каждого участка директор вычисляет взвешенную оценку:

```text
s = 0.4 * x1 + 0.6 * x2
```

Участок разрешено использовать, если одновременно выполнены два условия:

- `y == 1`;
- `s >= 5.0`.

Найдите количество разрешённых участков.

**Что сдаётся:** одно целое число.

В исходной официальной задаче оценка `s` сравнивалась с медианой всех оценок. В этой учебной версии граница `5.0` уже дана, чтобы сначала отдельно освоить вычисление взвешенной оценки и проверку двух условий. Оригинального файла данных в нашем архиве нет; `data.csv` — учебный набор.

## Простое объяснение

Коэффициенты показывают вклад каждого вида деревьев: число клёнов умножается на `0.4`, а число лип — на `0.6`. Полученные части складываются.

Например, при `x1 = 5` и `x2 = 5` оценка равна `0.4 * 5 + 0.6 * 5 = 5.0`. Но одной высокой оценки недостаточно: значение `y` тоже должно быть равно `1`.

Создайте собственный файл `.py` в этой папке. Готового решения и ответа здесь нет.

## Как это будет на платформе

В исходной официальной задаче участник скачивал таблицу в формате XLSX, ODS или CSV, вычислял оценки и их медиану, затем вводил одно число. В нашей упрощённой версии медиану вычислять не нужно. Код и таблицу вместо числового ответа не загружают.
