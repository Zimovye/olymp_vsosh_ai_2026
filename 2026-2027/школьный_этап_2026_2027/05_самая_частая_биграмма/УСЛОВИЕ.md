# Задача № 5: самая частая биграмма

## Условие задачи

Ограничение по времени: 1 секунда.

Ограничение по памяти: 256 мегабайт.

Лингвист Лиза изучает частотный анализ текстов. Её любимый объект изучения — биграммы.

Биграммой строки называется пара подряд идущих символов этой строки. Например, в строке `banana` ровно пять вхождений биграмм: `ba`, `an`, `na`, `an`, `na`. Биграммы на разных позициях считаются разными вхождениями, даже если состоят из одинаковых букв: в строке `banana` биграмма `an` встречается 2 раза, биграмма `na` — тоже 2 раза, а биграмма `ba` — один раз.

Именно частоты биграмм подсказывают лингвисту, на каком языке написан текст: например, в английских текстах часто встречается биграмма `th`.

Лизе досталась строка \(s\) длины \(n\), состоящая из строчных латинских букв. Чтобы усложнить себе задачу, Лиза выписала подряд \(k\) копий строки \(s\) и получила строку

\[
t=s+s+\ldots+s,
\]

состоящую из \(k\) копий строки \(s\), где знак `+` означает конкатенацию, то есть приписывание строк друг к другу.

Помогите Лизе найти биграмму, которая встречается в строке \(t\) наибольшее число раз, и посчитать это количество вхождений.

### Формат входных данных

В первой строке даны два целых числа \(n\) и \(k\) — длина строки \(s\) и количество её копий:

\[
1\leq n\leq 10^5,\qquad 1\leq k\leq 10^4.
\]

Во второй строке дана строка \(s\) из \(n\) строчных латинских букв.

Гарантируется, что \(n\cdot k\geq 2\), то есть в строке \(t\) есть хотя бы одно вхождение биграммы.

### Формат выходных данных

В первой строке выведите искомую биграмму — строку из двух строчных латинских букв.

Если подходящих биграмм несколько, выведите лексикографически наименьшую.

Во второй строке выведите одно целое число — количество вхождений этой биграммы в строку \(t\).

### Система оценивания

Тесты из условия не оцениваются. Остальные тесты оцениваются независимо друг от друга, каждый — в 1 балл.

| Группа | Тестов | Баллы | Дополнительные ограничения |
|---:|---:|---:|---|
| 1 | 3 | 3 | \(n\leq100,\ k\leq100\) |
| 2 | 3 | 3 | \(k=1\) |
| 3 | 6 | 6 | Без дополнительных ограничений |

### Замечание

В первом примере \(t=\texttt{abababab}\). Всего 7 вхождений биграмм: `ab` встречается 4 раза, `ba` — 3 раза.

Пример 1:

```text
Ввод
4 2
abab

Вывод

4
```

Пример 2:

```text
Ввод

Вывод

```

Пример 3:

```text

```

Пример 4:

```text

```

## Простое объяснение

Создавать строку \(t\) целиком нельзя: её длина может достигать \(10^9\). Вместо этого достаточно посчитать два вида биграмм.

1. Биграммы внутри строки \(s\). Каждая из них повторяется в каждой из \(k\) копий, поэтому её количество нужно умножить на \(k\).
2. Биграмма на стыке копий: последняя буква \(s\) и первая буква \(s\). Между \(k\) копиями имеется \(k-1\) стыков.

Например, для `s = aaba` и `k = 3` внутри одной копии встречаются `aa`, `ab`, `ba`. Каждая встречается трижды. На двух стыках появляется ещё две биграммы `aa`, поэтому итоговое количество `aa` равно \(3+2=5\).

После подсчёта биграммы просматриваются в лексикографическом порядке. Ответ заменяется только при строго большем количестве, поэтому при равенстве остаётся лексикографически наименьшая биграмма.

Сложность решения: \(O(n)\) по времени и не более \(O(26^2)\) по памяти.
