# Задача № 1: ранжирование пяти объектов

## Условие задачи

Решается задача ранжирования пяти объектов: между ними нужно распределить ранги с 1 по 5, не повторяя рангов. Известны релевантности этих объектов: 8, 3, 1, 1, 6.

Штраф за ранжирование вычисляется следующим образом: релевантность каждого объекта умножается на присвоенный ему ранг, после чего все полученные произведения складываются — так получается сумма `S`.

Найдите такое ранжирование (распределение рангов 1–5 между пятью объектами), при котором штраф `S` минимален. В ответ запишите значение этой минимальной суммы.

Источник: школьный этап ВсОШ по искусственному интеллекту 2026/27, задача № 1; условие предоставлено пользователем после завершения этапа.

## Простое объяснение

Большой ранг сильнее увеличивает произведение, поэтому его выгодно дать объекту с маленькой релевантностью. Например, число 8 лучше умножить на ранг 1, а не на ранг 5. Нужно поставить релевантности по убыванию, а ранги — по возрастанию, затем сложить произведения.
