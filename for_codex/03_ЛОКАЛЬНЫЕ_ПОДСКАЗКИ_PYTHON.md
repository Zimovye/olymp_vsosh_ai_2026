# Локальные учебные подсказки Python

Этот файл закрепляет порядок пополнения локального расширения `tools/python_hover_ru/`. Расширение используется только во время домашней подготовки: оно показывает рядом с английской подсказкой Pylance короткое объяснение на русском. Наличие расширения дома не означает, что им разрешено пользоваться во время официального тура.

## Где находятся файлы

- `tools/python_hover_ru/hints.json` — учебные объяснения;
- `tools/python_hover_ru/extension.js` — показ объяснения при наведении;
- `tools/python_hover_ru/README.md` — подключение расширения на компьютере и ручное добавление записи.

Обычно при занятиях изменяется только `hints.json`. Код расширения нужно менять лишь тогда, когда возможностей словаря действительно недостаточно.

## Правило пополнения

Когда в готовом примере, решении или исправлении появляется новая функция, метод или управляющая конструкция Python, которой ещё нет в `hints.json`, Codex в том же сеансе добавляет для неё подсказку. Отдельного напоминания ученика ждать не нужно.

Перед добавлением нужно проверить существующие ключи словаря. Не следует заранее заполнять справочник всеми функциями Python: добавляются только конструкции, которые реально встретились в текущем учебном коде или вызвали вопрос ученика.

Добавление подсказки не означает, что ученик уже освоил конструкцию. В `ПРОГРЕСС.md` отмечается только фактическая работа ученика, а не техническое расширение словаря.

## Как писать объяснение

Запись должна помогать новичку понять действие в текущем коде, а не дословно переводить официальную документацию. Для каждой конструкции нужны:

1. короткое название с понятным действием;
2. объяснение простыми словами;
3. маленький пример, связанный с текущей задачей, когда это уместно;
4. одно важное замечание о результате, изменении данных или частой ошибке.

Не использовать незнакомые термины без пояснения. Не перечислять все редкие параметры функции и не превращать подсказку в длинную лекцию. Если одно имя имеет много разных смыслов, давать только безопасное общее объяснение или отложить запись до появления поддержки контекста.

Пример структуры:

```json
"strip": {
  "title": "strip() — убрать лишнее по краям строки",
  "description": "Возвращает новую строку без пробелов и переносов строки в начале и конце.",
  "example": "clean_line = line.strip()",
  "note": "Исходная строка не меняется: результат нужно сохранить или сразу использовать."
}
```

## Проверка после изменения

После каждого изменения проверить синтаксис словаря:

```powershell
python -m json.tool tools/python_hover_ru/hints.json > $null
```

Затем сохранить файл и снова навести мышку на конструкцию в `.py`. Расширение перечитывает словарь при каждом наведении, поэтому после обычного пополнения `hints.json` перезагрузка и переустановка не требуются.

На втором компьютере расширение подключается один раз по инструкции из `tools/python_hover_ru/README.md`. После синхронизации проекта новые записи словаря становятся доступны через ту же папку расширения.
