# Простые подсказки Python на русском

Локальное расширение показывает короткие учебные объяснения при наведении на знакомые конструкции Python. Оно не использует интернет, переводчик или языковую модель.

## Подключение на компьютере

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File tools/python_hover_ru/install.ps1
```

После этого в VS Code выполнить `Developer: Reload Window`. Подключение делается один раз на каждом компьютере.

## Как добавить новую подсказку

Открыть `hints.json` и добавить запись:

```json
"имя_функции": {
  "title": "Короткое название",
  "description": "Объяснение простыми словами.",
  "example": "маленький пример",
  "note": "Что важно не перепутать."
}
```

Между соседними записями нужна запятая. Расширение перечитывает словарь при каждом наведении, поэтому переустанавливать его после изменения `hints.json` не требуется.

Обычная английская подсказка Pylance останется в окне. Русское объяснение появится отдельным блоком.
